  - title: Run both variants, interleaved, in fresh sandboxes
    brief: |
      The starter holds ScriptedAgent, a deterministic stand-in for a model plus one harness variant: its outcomes come from a generator seeded by variant, task and trial, so every run of the lab gives the same records. Write run_trials, which runs n trials of every task under every variant and returns one record per trial. Two rules come from how real evals go wrong. Every trial gets its own sandbox from make_sandbox(), because an agent that finds an earlier trial's leftovers can copy them; the mock does exactly that and counts it in leaks. And the variants are interleaved: at no point in the run may one variant be more than one trial ahead of the other, so a slow hour or a cluster hiccup lands on both arms instead of one.

      import random


      class ScriptedAgent:
          """A deterministic stand-in for one model plus one harness variant.

          Outcomes come from a generator seeded by (seed, variant, task, trial), so a rerun gives the same results.
          skill maps a task to the chance that a trial succeeds. memory_gb maps a task to the memory the agent needs
          for it; a sandbox with a lower memory_limit_gb ends the trial as an infra error. A trial that finds an earlier
          trial's notes in its sandbox copies the result and passes: the leak a reused environment causes.
          Every call is appended to ScriptedAgent.log, shared by all agents, in call order.
          """

          log = []

          def __init__(self, variant, skill, memory_gb=None, seed=0):
              self.variant = variant
              self.skill = skill
              self.memory_gb = memory_gb or {}
              self.seed = seed
              self.leaks = 0

          def run(self, task, trial, sandbox):
              ScriptedAgent.log.append((self.variant, task, trial))
              rng = random.Random(f"{self.seed}|{self.variant}|{task}|{trial}")
              turns = [
                  {"input": rng.randint(2000, 9000), "cached": rng.randint(0, 40000), "output": rng.randint(100, 900)}
                  for _ in range(rng.randint(3, 25))
              ]
              draw = rng.random()
              if sandbox.get("memory_limit_gb", float("inf")) < self.memory_gb.get(task, 0):
                  return {"ok": False, "infra_error": True, "turns": turns[:2]}
              notes = sandbox.setdefault("notes", {})
              if task in notes:
                  self.leaks += 1
                  ok = True
              else:
                  ok = draw < self.skill.get(task, 0.0)
              notes[task] = ok
              return {"ok": ok, "infra_error": False, "turns": turns}

          Return one record per trial: {"variant", "task", "trial", "ok", "infra_error", "turns"}.
          """

    solution: |
      from collections import defaultdict


      def counts(records, variant):
          cells = defaultdict(lambda: [0, 0])
          for r in records:
              if r["variant"] != variant or r["infra_error"]:
                  continue
              cells[r["task"]][0] += 1
              cells[r["task"]][1] += 1 if r["ok"] else 0
          return {t: (n, c) for t, (n, c) in cells.items()}


      def _all_of(n, c, k):
          # C(c, k) / C(n, k) as a running product, so large n needs no big integers.
          if n < k:
              raise ValueError(f"{n} usable trials cannot estimate a metric over k={k}")
          if c < k:
              return 0.0
          r = 1.0
          for i in range(k):
              r *= (c - i) / (n - i)
          return r


      def pass_hat_k(task_counts, k):
          if not task_counts or k < 1:
              raise ValueError("need k >= 1 and at least one task")
          return sum(_all_of(n, c, k) for n, c in task_counts.values()) / len(task_counts)


      def pass_at_k(task_counts, k):
          if not task_counts or k < 1:
              raise ValueError("need k >= 1 and at least one task")
          return sum(1.0 - _all_of(n, n - c, k) for n, c in task_counts.values()) / len(task_counts)

    solution: |
      def trial_cost(turns, prices):
          tokens = {"input": 0, "cached": 0, "output": 0}
          for t in turns:
              for kind in tokens:
                  tokens[kind] += t.get(kind, 0)
          return sum(tokens[kind] * prices[kind] for kind in tokens) / 1_000_000


      def summarize(records, variant, prices, k=1):
          mine = [r for r in records if r["variant"] == variant]
          trials = len(mine)
          if not trials:
              raise ValueError(f"no trials for variant {variant!r}")
          tc = counts(records, variant)
          spent = sum(trial_cost(r["turns"], prices) for r in mine)
          wins = sum(c for _, c in tc.values())
          return {
              "trials": trials,
              "infra_error_rate": sum(1 for r in mine if r["infra_error"]) / trials,
              "pass_hat_k": pass_hat_k(tc, k),
              "pass_at_k": pass_at_k(tc, k),
              "mean_cost": spent / trials,
              "mean_turns": sum(len(r["turns"]) for r in mine) / trials,
              "cost_per_success": spent / wins if wins else None,
          }

          a, b = counts(records_a, variant_a), counts(records_b, variant_b)
          shared = sorted(set(a) & set(b))
          if len(shared) < 2:
              raise ValueError("need at least two tasks with usable trials in both")
          d = [pass_hat_k({t: b[t]}, k) - pass_hat_k({t: a[t]}, k) for t in shared]
          mean = sum(d) / len(d)
          var = sum((x - mean) ** 2 for x in d) / (len(d) - 1)
          return {"tasks": len(shared), "diff": mean, "half_width": 1.96 * math.sqrt(var / len(d))}

    solution: |
      def verdict(run_a, variant_a, run_b, variant_b, max_infra_error_rate, k=1, ignore=()):
          def infra_rate(run, variant):
              mine = [r for r in run["records"] if r["variant"] == variant]
              return sum(1 for r in mine if r["infra_error"]) / len(mine) if mine else 0.0

          differs = mismatches(run_a, run_b, ignore)
          rates = {variant_a: infra_rate(run_a, variant_a), variant_b: infra_rate(run_b, variant_b)}
          p = paired(run_a["records"], variant_a, run_b["records"], variant_b, k)
          if differs or max(rates.values()) > max_infra_error_rate:
              call = "confounded"
          elif abs(p["diff"]) <= p["half_width"]:
              call = "inside_noise"
          else:
              call = variant_b if p["diff"] > 0 else variant_a
          return {"verdict": call, "diff": p["diff"], "half_width": p["half_width"], "differs": differs, "infra_error_rates": rates}

This lab builds the comparison the lessons in this module argue for, as one program. Each step adds functions to the same file and runs its tests against everything you have written so far, so step 6 calls the `run_trials` you wrote in step 1.

There is no model in the lab. `ScriptedAgent` stands in for a model plus one harness variant: each task has a success probability, outcomes come from a seeded generator, and the agent reproduces two failures real runs have. It needs a stated amount of memory for some tasks and ends the trial as an infra error when the sandbox has less, and it copies the answer when it finds an earlier trial's notes in its sandbox. The tests check behaviour (fresh sandboxes, interleaving, configurations that travel with results, statistics that match their definitions, verdicts that hold up on many seeds), never a particular sequence of outcomes beyond what the seed fixes.

Steps 1 to 3 are the runner and its report: trials, pass@k and pass^k, cost and turns. Step 4 records the configuration so a comparison across runs can be refused. Steps 5 and 6 compare two variants paired by task and decide whether the gap is a win, noise, or confounded.
