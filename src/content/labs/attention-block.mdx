  - title: Scaled dot-product attention
    brief: |
      Write the kernel every later step calls. softmax subtracts the row maximum before exponentiating, and a row whose every entry is minus infinity returns zeros instead of NaN, because minus infinity minus minus infinity is NaN. sdpa takes rows of queries, keys and values and an optional boolean mask where mask[i][j] is True when query i may read key j; blocked scores become minus infinity before the softmax, never zeroed weights after it.
    starter: |
      import math

      def softmax(row):
          """Stable softmax of a list of floats. A row of all -inf returns all zeros."""
          raise NotImplementedError

      def sdpa(Q, K, V, mask=None):
          """Scaled dot-product attention. Q, K, V are lists of rows. mask[i][j] is True when query i may read key j.
          Returns a list of len(Q) output rows, each of len(V[0])."""
          raise NotImplementedError
    tests: |

      assert softmax([float("-inf")] * 3) == [0.0, 0.0, 0.0], "an all-masked row is zeros, not NaN"
      assert close(softmax([1000.0, 0.0]), [1.0, 0.0]), "subtract the maximum so exp never overflows"

    solution: |
      import math

      def softmax(row):
          m = max(row)
          if m == float("-inf"):
              return [0.0] * len(row)
          e = [math.exp(x - m) for x in row]
          z = sum(e)
          return [x / z for x in e]

      def sdpa(Q, K, V, mask=None):
          scale = 1 / math.sqrt(len(K[0]))
          out = []
          for i, q in enumerate(Q):
              scores = [
                  scale * sum(a * b for a, b in zip(q, k)) if mask is None or mask[i][j] else float("-inf")
                  for j, k in enumerate(K)
              ]
              w = softmax(scores)
              out.append([sum(w[j] * V[j][c] for j in range(len(V))) for c in range(len(V[0]))])
          return out

    brief: |
      A decoder lets query i read keys 0 to i during training and prefill. Once a cache holds earlier keys, the queries in a call are the last n_q positions of a longer sequence, so the mask is aligned to the bottom-right corner: query i reads key j when j <= i + (n_k - n_q). FlashAttention made that alignment its default in version 2.1. The property the tests check is the one chunked prefill and speculative decoding rely on: attending with only the last few queries gives the same rows as the full square computation.

    brief: |
      Grouped-query attention keeps n_q query heads but only n_kv key and value heads, so keys and values are n_q / n_kv times narrower and so is everything a cache stores. Query head h reads key-value head h // (n_q // n_kv), the contiguous grouping of the repeat_kv helper in Hugging Face transformers. The test that matters is equivalence: GQA must equal multi-head attention run on keys and values repeated per group, without building that repeated copy to get there.

  - title: KV-cache decode equal to a full recompute
    brief: |
      Decode appends one token's keys and values to the cache and attends with that token's queries only, so each step costs work linear in the cache length instead of recomputing the square. Because row t of causal attention reads nothing after position t, the output of step t must equal row t of a full recompute; the tests compare every step. The cache stores n_kv heads, never the repeated copy, and nothing else that grows with the sequence: the hidden test counts the floats it holds.

      import math

      class KVCache:
          def __init__(self, n_q_heads, n_kv_heads, head_dim):
              if n_kv_heads < 1 or n_q_heads % n_kv_heads:
                  raise ValueError("n_q_heads must be a positive multiple of n_kv_heads")
              self.nq, self.nkv, self.d = n_q_heads, n_kv_heads, head_dim
              self.group = n_q_heads // n_kv_heads
              self.keys = [[] for _ in range(n_kv_heads)]
              self.values = [[] for _ in range(n_kv_heads)]

          def __len__(self):
              return len(self.keys[0])

          def step(self, q_row, k_row, v_row):
              ks, vs, qs = split_heads(k_row, self.nkv), split_heads(v_row, self.nkv), split_heads(q_row, self.nq)
              for g in range(self.nkv):
                  self.keys[g].append(ks[g])
                  self.values[g].append(vs[g])
              out = []
              for h in range(self.nq):
                  g = h // self.group
                  out.extend(sdpa([qs[h]], self.keys[g], self.values[g])[0])
              return out
  - title: Online softmax normaliser for long rows
    brief: |
      A long row does not need its scores in memory at once. Keep a state of three things, the running maximum m, the running denominator l and the unnormalised output acc; when a block raises the maximum, rescale l and acc by exp(m_old - m_new) before adding the block. That is the one-pass normaliser of Milakov and Gimelshein, the inner loop of FlashAttention, and, applied to two finished states, the merge Flash-Decoding uses to split one long cache across workers. The hidden test streams 100,000 keys through a generator under a memory ceiling and merges partial states in shuffled order.
    starter: |
      def empty_state(d_v):
          """The identity state: (m, l, acc) = (-inf, 0.0, [0.0] * d_v)."""
          raise NotImplementedError

      def update(state, q, keys, values, scale):
          """Fold one block of keys and values into state; return the new state."""
          raise NotImplementedError

      def merge(a, b):
          """Combine two states computed over disjoint key sets."""
          raise NotImplementedError

      def finish(state):
          """Output vector acc / l, or zeros if no key was seen."""
          raise NotImplementedError

      def online_attend(q, blocks, d_v):
          """blocks is an iterable of (keys, values); read it once, never hold more than one block."""
          raise NotImplementedError

      close = lambda a, b, tol=1e-9: all(abs(x - y) < tol for x, y in zip(a, b))

    solution: |
      import math

      def empty_state(d_v):
          return (float("-inf"), 0.0, [0.0] * d_v)

      def update(state, q, keys, values, scale):
          m, l, acc = state
          scores = [scale * sum(a * b for a, b in zip(q, k)) for k in keys]
          if not scores:
              return state
          m_new = max(m, max(scores))
          c = math.exp(m - m_new) if m != float("-inf") else 0.0
          l = l * c
          acc = [x * c for x in acc]
          for s, v in zip(scores, values):
              p = math.exp(s - m_new)
              l += p
              for i, x in enumerate(v):
                  acc[i] += p * x
          return (m_new, l, acc)

      def merge(a, b):
          (ma, la, xa), (mb, lb, xb) = a, b
          if ma == float("-inf"):
              return b
          if mb == float("-inf"):
              return a
          m = max(ma, mb)
          ca, cb = math.exp(ma - m), math.exp(mb - m)
          return (m, la * ca + lb * cb, [x * ca + y * cb for x, y in zip(xa, xb)])

      def finish(state):
          m, l, acc = state
          return [0.0] * len(acc) if l == 0.0 else [x / l for x in acc]

      def online_attend(q, blocks, d_v):
          scale = 1 / math.sqrt(len(q))
          state = empty_state(d_v)
          for keys, values in blocks:
              state = update(state, q, keys, values, scale)
          return finish(state)

This lab builds the attention layer from the mechanics lesson as one program. Each step adds functions to the same file and runs its tests against everything written so far, so the decode step in step 5 is checked against the `gqa` you wrote in step 4.

Steps 1 to 4 are the forward pass in the shapes serving code uses: a stable softmax, a causal mask aligned for a query block that sits at the end of a longer sequence, heads, and grouped key-value heads. Step 5 is the decode loop, tested against a full recompute at every position, with the cache's size checked against what grouped-query attention promises. Step 6 is the normaliser that lets a kernel or a pool of workers process one long row in pieces.

Your code is saved with your progress as you type. Passing a step's tests unlocks the next step and counts toward your streak. Python runs in your browser with the standard library only.
