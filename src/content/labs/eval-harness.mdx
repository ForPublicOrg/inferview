    solution: |
      import hashlib
      import json


      def load_golden(text):
          items, seen = [], set()
          for n, line in enumerate(text.splitlines(), 1):
              if not line.strip():
                  continue
              row = json.loads(line)
              if not isinstance(row.get("id"), str) or not isinstance(row.get("output"), str):
                  raise ValueError(f"line {n}: id and output are required strings")
              if row.get("label") not in ("pass", "fail"):
                  raise ValueError(f"line {n}: label must be 'pass' or 'fail'")
              if row["id"] in seen:
                  raise ValueError(f"line {n}: duplicate id {row['id']}")
              seen.add(row["id"])
              items.append({"id": row["id"], "output": row["output"], "label": row["label"], "tags": sorted(row.get("tags", []))})
          items.sort(key=lambda r: r["id"])
          canonical = json.dumps(items, sort_keys=True, separators=(",", ":"))
          return {"version": hashlib.sha256(canonical.encode()).hexdigest()[:12], "items": items}
  - title: A binary judge against a scripted mock
    brief: |
      ScriptedJudgeModel stands in for the judge model: it returns scripted replies to prompts that contain a given substring, in order, and records every prompt in calls. Write judge(model, criterion, output), which asks for a short critique followed by a final line "Verdict: PASS" or "Verdict: FAIL" and returns "pass", "fail" or None. The verdict is read from the last line that starts with "Verdict:", in any case and with trailing punctuation, never from a pass or fail word inside the critique. A reply with no readable verdict gets one retry with the same prompt; after a second unreadable reply the judge abstains with None. There is never a third call for one output, because a judge that retries until it gets an answer turns a parsing failure into a hidden cost.
    starter: |
      class ScriptedJudgeModel:
          """A deterministic stand-in for the judge model. replies maps a substring of the prompt
          to the replies returned, in order, to prompts that contain it; the last reply repeats.
          Prompts that match no key get default. Every prompt is appended to calls."""

          def __init__(self, replies, default="Critique: meets the criterion.\nVerdict: PASS"):
              self.replies = {k: list(v) for k, v in replies.items()}
              self.default = default
              self.calls = []

          def complete(self, prompt):
              self.calls.append(prompt)
              for key, queue in self.replies.items():
                  if key in prompt:
                      return queue.pop(0) if len(queue) > 1 else queue[0]
              return self.default


      def judge(model, criterion, output):
          """Ask model for a critique and a final "Verdict: PASS" or "Verdict: FAIL" line.
          Return "pass", "fail", or None after two replies without a readable verdict.
          Never call the model more than twice for one output."""
          raise NotImplementedError

    solution: |
      def rates(golden, verdicts):
          tp = fn = tn = fp = abstained = 0
          for item in golden["items"]:
              if item["id"] not in verdicts:
                  raise ValueError(f"no verdict for {item['id']}")
              v = verdicts[item["id"]]
              abstained += v is None
              if item["label"] == "fail":
                  tp += v == "fail"
                  fn += v != "fail"
              else:
                  tn += v == "pass"
                  fp += v != "pass"
          if tp + fn == 0 or tn + fp == 0:
              raise ValueError("the golden set needs at least one pass and one fail")
          return {"version": golden["version"], "tpr": tp / (tp + fn), "tnr": tn / (tn + fp),
                  "failures": tp + fn, "passes": tn + fp, "abstained": abstained}

    solution: |
      import random


      def _theta(p, tpr, tnr):
          return min(1.0, max(0.0, (p + tpr - 1) / (tpr + tnr - 1)))


      def corrected(r, production, confidence=0.95, iterations=2000, seed=0):
          if r["tpr"] + r["tnr"] <= 1:
              raise ValueError("the judge is no better than chance")
          kept = [v for v in production if v is not None]
          if not kept:
              raise ValueError("no usable production verdicts")
          n, k = len(kept), kept.count("pass")
          p = k / n
          est = _theta(p, r["tpr"], r["tnr"])
          rng, nf, np_ = random.Random(seed), r["failures"], r["passes"]
          draws, undefined = [], 0
          for _ in range(iterations):
              t = rng.binomialvariate(nf, r["tpr"]) / nf
              s = rng.binomialvariate(np_, r["tnr"]) / np_
              if t + s <= 1:
                  undefined += 1
                  continue
              draws.append(_theta(rng.binomialvariate(n, p) / n, t, s))
          alpha = 1 - confidence
          if undefined > alpha / 2 * iterations:
              lo, hi = 0.0, 1.0
          else:
              draws.sort()
              lo = min(est, draws[int(alpha / 2 * (len(draws) - 1))])
              hi = max(est, draws[int((1 - alpha / 2) * (len(draws) - 1))])
          return {"estimate": est, "low": lo, "high": hi, "observed": p, "n": n, "dropped": len(production) - n}

      from math import comb


      def pass_hat_k(trials, k):
          if k < 1 or not trials:
              raise ValueError("k must be at least 1 and there must be at least one item")
          total = 0.0
          for item, verdicts in trials.items():
              n, c = len(verdicts), verdicts.count("pass")
              if n < k:
                  raise ValueError(f"{item} has {n} trials, fewer than k = {k}")
              total += comb(c, k) / comb(n, k)
          return total / len(trials)

      from math import sqrt


      def gate(baseline, candidate, margin=0.02, z=1.96):
          if baseline["version"] != candidate["version"]:
              raise ValueError("the runs used different golden set versions")
          if set(baseline["results"]) != set(candidate["results"]) or not baseline["results"]:
              raise ValueError("the runs must cover the same, non-empty set of items")
          d = [(candidate["results"][i] == "pass") - (baseline["results"][i] == "pass") for i in baseline["results"]]
          n = len(d)
          mean = sum(d) / n
          var = sum((x - mean) ** 2 for x in d) / (n - 1) if n > 1 else 0.0
          se = sqrt(var / n)
          lower = mean - z * se
          return {"version": baseline["version"], "diff": mean, "se": se, "lower": lower,
                  "decision": "ship" if lower >= -margin else "block"}

      def report(golden, r, corr, g, min_failures=30, min_per_tag=5, max_width=0.10):
          gaps = []
          if r["version"] != g["version"]:
              gaps.append({"kind": "judge_version", "detail": f"judge validated on {r['version']}, gate ran on {g['version']}"})
          if r["failures"] < min_failures:
              gaps.append({"kind": "few_failures", "detail": f"TPR rests on {r['failures']} labelled failures"})
          if r["abstained"]:
              gaps.append({"kind": "abstentions", "detail": f"{r['abstained']} golden items got no verdict"})
          if corr["high"] - corr["low"] > max_width:
              gaps.append({"kind": "wide_interval", "detail": f"pass rate between {corr['low']:.3f} and {corr['high']:.3f}"})
          fails_by_tag = {}
          for item in golden["items"]:
              for tag in item["tags"]:
                  fails_by_tag.setdefault(tag, 0)
                  fails_by_tag[tag] += item["label"] == "fail"
          for tag, count in sorted(fails_by_tag.items()):
              if count < min_per_tag:
                  gaps.append({"kind": "thin_tag", "tag": tag, "detail": f"{count} labelled failures tagged {tag}"})
          decision = "hold" if r["version"] != g["version"] else g["decision"]
          return {"version": golden["version"], "decision": decision,
                  "pass_rate": (corr["estimate"], corr["low"], corr["high"]),
                  "judge": {k: r[k] for k in ("tpr", "tnr", "failures", "passes")}, "not_checked": gaps}

This lab builds the measurement chain the lessons in this module argue for, as one program. Each step adds functions to the same file and runs its tests against everything written so far, so step 7's report reads the golden set from step 1, the rates from step 3 and the interval from step 4.

There is no model in the lab. `ScriptedJudgeModel` returns scripted replies to prompts that contain a given substring, so the tests can feed the judge a critique that mentions the wrong word, a reply with no verdict, or a verdict that changes on the last line, and then check what the judge did: which verdict it returned and how many calls it made. Labels and production verdicts in the tests come from seeded generators, and the tests check properties (rates that match their definitions, intervals that widen when failures are scarce, decisions at the gate's boundary) rather than a particular output.

Steps 1 to 4 are validation: a golden set with an identity, a judge with a strict output contract, its error rates with failure as the positive class, and the corrected pass rate. Steps 5 and 6 are release decisions: reliability over repeated runs and a paired gate. Step 7 writes down what none of it measured.
