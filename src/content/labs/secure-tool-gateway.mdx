  - title: Label every value with its origin
    brief: |
      Everything the agent handles becomes a Value: the data and the frozenset of Sources it was computed from, each source marked trusted or not and private or not. derive runs ordinary code on Values and unions the sources of everything it read, so an upper-cased page is still the page. The gateway runs a tool on raw arguments and labels the result with a Source built from the tool's flags plus the arguments' sources. Compute the source set when a Value is made, not by walking its history at check time, and walk containers with an explicit stack: the hidden test hands sources_of a list of 100,001 Values. Printing a Value must not show its data, or one f-string turns a labelled secret into a plain string.
    starter: |
      from collections import namedtuple

      # A source is where data entered the system: trusted (the user, the planner's own constants) or not, private or not.
      Source = namedtuple("Source", "name trusted private")
      USER = Source("user", True, False)

      # A tool and what its results are: untrusted (web pages, inbound mail), private (the inbox, a profile),
      # outbound (it sends data out). dest names the argument that holds a URL or address (step 3).
      Tool = namedtuple("Tool", "fn untrusted private outbound dest", defaults=(False, False, False, None))


      class Refused(Exception):
          def __init__(self, tool, rule):
              super().__init__("%s refused: %s" % (tool, rule))
              self.tool, self.rule = tool, rule


      class Value:
          """Data plus .sources, the frozenset of every Source it was computed from.
          .untrusted and .private say whether any of those sources is. Printing a Value must not show its data."""

          def __init__(self, data, sources=()):
              raise NotImplementedError


      def ingest(data, source):
          """Data entering from one source."""
          raise NotImplementedError


      def sources_of(x):
          """The union of sources in x: a Value, a plain constant (no sources), or a list, tuple or dict holding either."""
          raise NotImplementedError


      def raw(x):
          """x with every Value replaced by its data, inside lists, tuples and dicts too."""
          raise NotImplementedError


      def derive(fn, *args):
          """fn applied to the raw args, as a Value."""
          raise NotImplementedError


      class Gateway:
          def __init__(self, tools):
              self.tools = dict(tools)
              self.ran = []  # names of the tools that actually ran, in order

          def check(self, name, tool, args):
              """Raise Refused to stop a call before it runs. Later steps add rules here."""

          def commit(self, name, tool, args):
              """Called after a tool ran."""

          def call(self, name, **args):
              """Run a tool on raw arguments and return its result as a Value labelled with Source("tool:<name>", ...)
              from the tool's flags. An unknown tool is refused with rule "unknown-tool"."""
              raise NotImplementedError

    solution: |
      from collections import namedtuple

      Source = namedtuple("Source", "name trusted private")
      USER = Source("user", True, False)

      Tool = namedtuple("Tool", "fn untrusted private outbound dest", defaults=(False, False, False, None))


      class Refused(Exception):
          def __init__(self, tool, rule):
              super().__init__("%s refused: %s" % (tool, rule))
              self.tool, self.rule = tool, rule


      class Value:
          __slots__ = ("data", "sources")

          def __init__(self, data, sources=()):
              self.data = data
              self.sources = frozenset(sources)

          @property
          def untrusted(self):
              return any(not s.trusted for s in self.sources)

          @property
          def private(self):
              return any(s.private for s in self.sources)

          def __repr__(self):
              return "Value(<hidden>, from %s)" % ", ".join(sorted(s.name for s in self.sources))

          __str__ = __repr__

          def __format__(self, spec):
              return repr(self)


      def ingest(data, source):
          return Value(raw(data), {source} | sources_of(data))


      def sources_of(x):
          # Iterative, so a long list of Values costs one pass and nothing recurses per element.
          found, stack = set(), [x]
          while stack:
              item = stack.pop()
              if isinstance(item, Value):
                  found |= item.sources
              elif isinstance(item, (list, tuple)):
                  stack.extend(item)
              elif isinstance(item, dict):
                  stack.extend(item.values())
          return frozenset(found)


      def raw(x):
          if isinstance(x, Value):
              return x.data
          if isinstance(x, list):
              return [raw(i) for i in x]
          if isinstance(x, tuple):
              return tuple(raw(i) for i in x)
          if isinstance(x, dict):
              return {k: raw(v) for k, v in x.items()}
          return x


      def derive(fn, *args):
          out = fn(*[raw(a) for a in args])
          return Value(raw(out), sources_of(args) | sources_of(out))


      class Gateway:
          def __init__(self, tools):
              self.tools = dict(tools)
              self.ran = []

          def check(self, name, tool, args):
              pass

          def commit(self, name, tool, args):
              pass

          def call(self, name, **args):
              if name not in self.tools:
                  raise Refused(name, "unknown-tool")
              tool = self.tools[name]
              self.check(name, tool, args)
              out = tool.fn(**{k: raw(v) for k, v in args.items()})
              self.ran.append(name)
              self.commit(name, tool, args)
              # The result also carries the arguments' sources: a search run on an attacker's query returns what the attacker chose.
              origin = Source("tool:" + name, not tool.untrusted, tool.private)
              return Value(raw(out), {origin} | sources_of(list(args.values())) | sources_of(out))
  - title: Refuse calls combining untrusted input, private data and an outbound channel
    brief: |
      Meta's Agents Rule of Two allows a session at most two of [A] untrusted input, [B] private data and [C] an outbound or state-changing action without supervision. Track the legs the session has used, and refuse with rule "rule-of-two" any call that would give it all three, whichever leg that call adds. A refusal goes to approve(name, raw_args) when one is configured, so a person can let it through after seeing exactly what would be sent. lock_outbound() is Meta's one-way switch: after it, outbound calls are refused for good and the session no longer counts C, so a research session that browsed and posted can go on to read private data. Whether a session that sent something before it read untrusted input may then read private data is your call; the tests only require that no outbound call runs after both A and B entered the session without approval, and that a two-leg session is never refused.

              self.approve = approve
              raise NotImplementedError

              raise NotImplementedError

              raise NotImplementedError

              super().check(name, tool, args)
              self.rule_of_two(name, tool, args)

    solution: |
      class Gateway(Gateway):
          def __init__(self, tools, approve=None):
              super().__init__(tools)
              self.approve = approve
              self.legs = frozenset()
              self.outbound_locked = False

          def legs_of(self, tool, args):
              found = sources_of(list(args.values()))
              legs = set()
              if tool.untrusted or any(not s.trusted for s in found):
                  legs.add("A")
              if tool.private or any(s.private for s in found):
                  legs.add("B")
              if tool.outbound:
                  legs.add("C")
              return legs

          def lock_outbound(self):
              self.outbound_locked = True
              self.legs = self.legs - {"C"}

          def rule_of_two(self, name, tool, args):
              if tool.outbound and self.outbound_locked:
                  raise Refused(name, "outbound-locked")
              if self.legs | self.legs_of(tool, args) >= {"A", "B", "C"}:
                  if not (self.approve and self.approve(name, {k: raw(v) for k, v in args.items()})):
                      raise Refused(name, "rule-of-two")

          def check(self, name, tool, args):
              super().check(name, tool, args)
              self.rule_of_two(name, tool, args)

          def commit(self, name, tool, args):
              super().commit(name, tool, args)
              self.legs = self.legs | self.legs_of(tool, args)
  - title: An egress allowlist
    brief: |
      Every tool with a dest argument (a URL or an email address) is checked before anything else, and approval cannot override it. The host must be on the allowlist: exact names, and "*.suffix" entries that match at a label boundary at any depth but never the suffix itself; a bare "*" is refused when the gateway is built. The destination must also be built only from trusted, non-private sources (rule "destination"): an allowlisted upload host with an attacker's bucket in the path, or an allowlisted page with the inbox in its query string, passes a host check and fails this one. This is Meta's travel control, web requests only to URLs from trusted sources, applied to every destination, and it is why fetch can count as a read: its URL cannot carry data the session holds. In this scenario the allowlist is generated from every tenant's configuration and has 200,000 entries, so build an index once; the hidden test times 40,000 lookups.

              raise NotImplementedError

              raise NotImplementedError

      def valid_schema(schema):
          if not isinstance(schema, (list, tuple)) or not schema:
              return False
          if schema[0] == "yes-no":
              return len(schema) == 1
          if schema[0] == "choice":
              return len(schema) == 2 and isinstance(schema[1], (list, tuple)) and all(isinstance(o, str) for o in schema[1])
          if schema[0] == "text":
              return len(schema) == 2 and isinstance(schema[1], int) and schema[1] > 0
          return False


      def conforms(out, schema):
          if not isinstance(out, str) or not valid_schema(schema):
              return False
          if schema[0] == "yes-no":
              return out in ("yes", "no")
          if schema[0] == "choice":
              return out in schema[1]
          return len(out) <= schema[1]


      class Executor(Executor):
          def __init__(self, planner, gateway, qmodel=None, max_steps=20):
              super().__init__(planner, gateway, max_steps)
              self.qmodel = qmodel

          def check_step(self, n, step):
              if not (isinstance(step, dict) and "ask" in step):
                  return super().check_step(n, step)
              refs = step.get("on") if isinstance(step.get("on"), list) else [step.get("on")]
              if self.qmodel is None or not isinstance(step["ask"], str) or not valid_schema(step.get("schema")) or not refs:
                  raise PlanError("step %d is not a valid ask" % n)
              for r in refs:
                  if not (isinstance(r, str) and REF.fullmatch(r)):
                      raise PlanError("step %d asks about %r, which is not a step" % (n, r))
                  self.check_ref(r, n)

          def ask(self, n, step, outputs, request):
              on = step["on"]
              values = [self.resolve(r, outputs, request) for r in (on if isinstance(on, list) else [on])]
              data = raw(values) if isinstance(on, list) else raw(values[0])
              out = self.qmodel(step["ask"], data)
              if not conforms(out, step["schema"]):
                  raise QuarantineError("step %d: the answer does not fit %r" % (n, step["schema"]))
              # The answer is a function of what the model read, so it keeps those sources; this is what stops laundering.
              return Value(out, sources_of(values) | request.sources)

          def step(self, n, step, outputs, request):
              if "ask" in step:
                  return self.ask(n, step, outputs, request)
              return super().step(n, step, outputs, request)

This lab builds the gateway that sits between an agent's planner and its tools, as one program. Each step adds to the same file and runs its tests against everything you have written so far, so the attack suite in step 6 depends on the labels from step 1, the session rule from step 2, the allowlist from step 3, the frozen plan from step 4 and the quarantine and renderer from step 5.

Nothing calls a model or the network. The planner and the quarantined model are deterministic mocks that live in the starters: ScriptedPlanner returns a scripted plan and, like a model that obeys instructions wherever it reads them, adds a step for every "DO" line in text it is shown; ScriptedQModel returns scripted answers and obeys an "ANSWER" line in the data it reads. World fakes the inbox, the web, mail and uploads, and records every effect. The tests assert behaviour: which tools ran, which calls were refused and by which rule, what was sent where, and what the user was shown. They never compare prose.

The layers are of two kinds, and the lab keeps them apart. The labels, the session rule, the allowlist, the frozen plan and the render rule are deterministic: each holds for every input, and its tests are property tests. Nothing here lowers a rate, so the lab has no classifier; in production a classifier sits in front as a layer that reduces how often these controls are tested, never as the reason the system is safe.

Two limits remain after the last step. The quarantined model can still be told what to write, and a misleading summary is correctly labelled and still misleads; CaMeL lists such text-only attacks as a non-goal. And Python lets any code read a Value's data and build a plain string from it, which drops the label; CaMeL runs the plan in its own interpreter for that reason, and a production version of this gateway runs the planner's program the same way rather than trusting the code around it.
