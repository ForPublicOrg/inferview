  - title: Group the notes into categories
    brief: |
      Axial coding: put every note's (trace, step) anchor into exactly one category in AXIAL, and give each category a pass/fail rule in DEFINITIONS that a second labeller could apply to a trace without asking you. Three to eight categories, named in lowercase words joined by hyphens, and no catch-all: a bucket called other is a taxonomy you have not finished. Name categories after what went wrong in the system (the search, the arguments, the reply's sources), because that is what someone fixes. The hidden tests compare your grouping with the key's on the anchors you share, never by name: at least 75% of your anchors sit with the key's majority category in their group, and at least 70% of the key's anchors sit with your majority category in theirs, so merging two of the key's categories or splitting one costs you, and renaming costs nothing.

      import math


      def wilson(k, n, z=1.96):
          p = k / n
          d = 1 + z * z / n
          centre = (p + z * z / (2 * n)) / d
          half = z / d * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n))
          return max(0.0, centre - half), min(1.0, centre + half)


      def rank(first, table):
          n = len(table)
          cats = sorted({c for row in table.values() for c in row})
          rows = []
          for c in cats:
              k = sum(1 for v in first.values() if v is not None and v[1] == c)
              low, high = wilson(k, n)
              rows.append({"category": c, "first": k, "present": sum(row.get(c, 0) for row in table.values()),
                           "share": k / n, "low": low, "high": high})
          rows.sort(key=lambda r: (-r["first"], -r["present"], r["category"]))
          return rows


      def saturation(first, order):
          seen, curve = set(), []
          for tid in order:
              if first.get(tid) is not None:
                  seen.add(first[tid][1])
              curve.append(len(seen))
          return curve
