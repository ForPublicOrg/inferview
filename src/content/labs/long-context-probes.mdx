  - title: Single needle
    brief: |
      The needle test plants one fact in filler and sweeps context length and the depth at which the fact sits. Build its three parts: haystack, which returns exactly n_words seeded filler words; place, which inserts sentences at fractional depths without touching the input list; and needle_probe, which runs one model call per (length, depth) cell and scores 1 when the answer contains the planted code. The mock model at the top of the file answers any question that repeats the needle's words from anywhere in the context, so expect a perfect grid. That perfect grid is the reason the rest of this lab exists.

          A question that repeats the needle's own words is answered from anywhere in the context.
          A question that needs an association, a second hop or a count is answered only from the

          def complete(self, prompt):

              words = context.split()

              else:
                  seen = full
              m = re.fullmatch(r"What is the code for vault (\w+)\?", question)
              if m:
                  hit = re.search(r"vault %s is (\d+)" % m.group(1), full)
                  return hit.group(1) if hit else "I could not find it."
              m = re.fullmatch(r"List the codes for vaults ([\w, ]+)\.", question)
              if m:
                  out = []
                  for name in [n.strip() for n in m.group(1).split(",")]:
                      hit = re.search(r"vault %s is (\d+)" % name, full)
                      if hit:
                          out.append("%s=%s" % (name, hit.group(1)))
                  return "; ".join(out)

              return "I do not understand the question."

      def tag(rng, n=6):
          return "".join(rng.choice(string.ascii_uppercase) for _ in range(n))


      def haystack(n_words, seed):
          rng = random.Random("hay:%s:%s" % (seed, n_words))
          return [rng.choice(FILLER) for _ in range(n_words)]


      def place(words, sentences, depths):
          if len(sentences) != len(depths):
              raise ValueError("one depth per sentence")
          n = len(words)
          # insert from the back so earlier positions still refer to the original list
          inserts = sorted(((min(n, max(0, round(d * n))), k) for k, d in enumerate(depths)), reverse=True)
          out = list(words)
          for pos, k in inserts:
              out[pos:pos] = sentences[k].split()
          return out


      def ask(model, words, question):
          return model.complete(" ".join(words) + "\nQUESTION: " + question)


      def needle_probe(model, lengths, depths, seed=0):
          rows = []
          for length in lengths:
              for depth in depths:
                  rng = random.Random("needle:%s:%s:%s" % (seed, length, depth))
                  vault, code = tag(rng), str(rng.randint(10000, 99999))
                  words = place(haystack(length, seed), ["The code for vault %s is %s." % (vault, code)], [depth])
                  answer = ask(model, words, "What is the code for vault %s?" % vault)
                  rows.append({"task": "needle", "length": length, "depth": depth,
                               "score": 1.0 if re.search(r"\b%s\b" % code, answer) else 0.0})
          return rows

      def multi_needle_probe(model, lengths, k=4, seed=0):
          rows = []
          for length in lengths:
              rng = random.Random("multi:%s:%s:%s" % (seed, length, k))
              vaults = []
              while len(vaults) < k:
                  name = tag(rng)
                  if name not in vaults:
                      vaults.append(name)
              codes = [str(rng.randint(10000, 99999)) for _ in vaults]
              sentences = ["The code for vault %s is %s." % (v, c) for v, c in zip(vaults, codes)]
              words = place(haystack(length, seed), sentences, [(i + 0.5) / k for i in range(k)])
              answer = ask(model, words, "List the codes for vaults %s." % ", ".join(vaults))
              got = dict(re.findall(r"(\w+)=(\d+)", answer))
              hits = sum(1 for v, c in zip(vaults, codes) if got.get(v) == c)
              rows.append({"task": "multi_needle", "length": length, "depth": None, "score": hits / k})
          return rows

      STOPWORDS = {"a", "an", "the", "to", "of", "in", "has", "been", "which", "who", "is", "next", "actually"}


      def content_words(text):
          return set(re.findall(r"[a-z]+", text.lower())) - STOPWORDS


      def no_overlap_case(rng):
          name = rng.choice(NAMES)
          landmark = rng.choice(sorted(LANDMARKS))
          needle = "Actually, %s lives next to the %s." % (name, landmark)
          question = "Which person has been to %s?" % LANDMARKS[landmark]
          if content_words(needle) & content_words(question):
              raise ValueError("needle and question overlap")
          return needle, question, name


      def no_overlap_probe(model, lengths, depths, seed=0):
          rows = []
          for length in lengths:
              for depth in depths:
                  rng = random.Random("nolima:%s:%s:%s" % (seed, length, depth))
                  needle, question, name = no_overlap_case(rng)
                  answer = ask(model, place(haystack(length, seed), [needle], [depth]), question)
                  rows.append({"task": "no_overlap", "length": length, "depth": depth,
                               "score": 1.0 if re.search(r"\b%s\b" % name, answer) else 0.0})
          return rows

      def chain_probe(model, lengths, hops=3, seed=0):
          rows = []
          for length in lengths:
              rng = random.Random("chain:%s:%s:%s" % (seed, length, hops))

      NEEDLE_TASKS = ("needle", "multi_needle")
      REALISTIC_TASKS = ("no_overlap", "chain", "aggregation")


      def score_by_length(rows):
          sums = {}
          for r in rows:
              cell = sums.setdefault(r["task"], {}).setdefault(r["length"], [0.0, 0])
              cell[0] += r["score"]
              cell[1] += 1
          return {t: {L: s / n for L, (s, n) in sorted(c.items())} for t, c in sums.items()}


      def effective_length(by_length, threshold=0.9):
          best = 0
          for length in sorted(by_length):
              if by_length[length] < threshold:
                  break
              best = length
          return best


      def report(rows, threshold=0.9):
          scores = score_by_length(rows)
          eff = {t: effective_length(s, threshold) for t, s in scores.items()}
          realistic = [t for t in REALISTIC_TASKS if t in scores]
          if not realistic:
              raise ValueError("no realistic task in the rows; a needle score is not a context claim")
          needles = [t for t in NEEDLE_TASKS if t in scores]

          def line(t):
              cells = "  ".join("%d: %.2f" % (L, s) for L, s in scores[t].items())
              return "  %-12s %s  (holds to %d)" % (t, cells, eff[t])

          lines = ["Tasks that predict use (threshold %.2f):" % threshold] + [line(t) for t in realistic]
          lines.append("Effective context: %d" % min(eff[t] for t in realistic))
          if needles:
              lines += ["Needle tasks, reported apart (a pass here is not evidence of usable context):"]
              lines += [line(t) for t in needles]
          return {"scores": scores, "effective_length": eff,
                  "effective_context": min(eff[t] for t in realistic),
                  "needle_context": max((eff[t] for t in needles), default=0), "lines": lines}


      def run_suite(model, lengths, seed=0, depths=(0.0, 0.5, 1.0), threshold=0.9):
          rows = needle_probe(model, lengths, depths, seed)
          rows += multi_needle_probe(model, lengths, seed=seed)
          rows += no_overlap_probe(model, lengths, depths, seed)
          rows += chain_probe(model, lengths, seed=seed)
          rows += aggregation_probe(model, lengths, seed=seed)
          return report(rows, threshold)

This lab builds the probe suite the lesson [Testing long context honestly](/learn/multimodal/long-context/long-context-evals) argues for, as one program. Each step adds functions to the same file and runs its tests against everything written so far, so the report in step 6 runs the probes from steps 1 to 5.

There is no model in the lab. `MockLongContextModel` is a scripted stand-in with one built-in weakness: it answers a question that repeats the needle's own words from anywhere in the context, and it answers a question that needs an association, a second hop or a count only from the first 2,000 and last 2,000 words. That is a caricature of the pattern Lost in the Middle reported (best at the start and end of the input, worse in the middle), chosen because it makes the needle test pass at every length while the other four probes fail past 4,000 words, which is the gap RULER, NoLiMa and HELMET each found in real models. The tests check behaviour: how many calls a probe makes, what the prompt contains, which scores move with length, and that the report never takes its context figure from a needle task.

Steps 1 and 2 are the needle tests as most model cards run them. Steps 3 to 5 are the probes that remove the literal match: an association, a chain of assignments and a count. Step 6 turns the rows into the table you would put in a design document and the one number you would let anyone quote.
