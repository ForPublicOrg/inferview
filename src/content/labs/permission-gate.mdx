  - title: Match rules, deny before ask before allow
    brief: |
      Start with one simple command. Deny beats ask beats allow whatever the specificity, so a deny on rm wins over an allow for rm -rf build, and Claude Code documents the same order. Match whole words, not string prefixes. Deny and ask rules should still fire through a path to the program (/bin/rm) and the wrappers timeout, time, nice and nohup; allow rules match only the bare name, because the agent can write a file called ./ls. Index the rules by first word: the hidden tests time a gate with 40,000 rules.
    starter: |
      ORDER = ("deny", "ask", "allow")
      STRICT = {"allow": 0, "ask": 1, "deny": 2}


      def strictest(decisions):
          """The most restrictive of several decisions; later steps use it for compound commands."""
          return max(decisions, key=STRICT.__getitem__, default="allow")


      class Gate:
          """A permission gate for an agent's shell tool.

          rules: {"deny": [[words]], "ask": [[words]], "allow": [[words]]}. A rule matches a command whose first words
          are the rule's words: ["git", "push"] matches "git push origin main" and not "git pushx". Generated configs
          hold tens of thousands of rules. Later steps pass extra keyword options; accept and keep them.
          """

          def __init__(self, rules, **options):
              raise NotImplementedError

          def check_part(self, argv):
              """Decide one simple command given as a list of words: "deny", "ask" or "allow"."""
              raise NotImplementedError

          def check(self, command):
              """Decide one simple command given as a string. Step 2 replaces this to handle chains."""
              raise NotImplementedError

    solution: |
      ORDER = ("deny", "ask", "allow")
      STRICT = {"allow": 0, "ask": 1, "deny": 2}
      WRAPPERS = {"timeout", "time", "nice", "nohup"}


      def strictest(decisions):
          return max(decisions, key=STRICT.__getitem__, default="allow")


      def unwrap(argv):
          """Drop timeout, time, nice and nohup with their options, so the program that runs comes first."""
          while argv and argv[0] in WRAPPERS:
              head, argv = argv[0], argv[1:]
              while argv and argv[0].startswith("-"):
                  flag, argv = argv[0], argv[1:]
                  if head == "nice" and flag == "-n":
                      argv = argv[1:]
              if head == "timeout":
                  argv = argv[1:]
          return argv


      class Gate:
          def __init__(self, rules, **options):
              self.options = options
              # Rules indexed by first word: a lookup costs one dict probe, not a pass over every rule.
              self.index = {k: {} for k in ORDER}
              for kind in ORDER:
                  for rule in rules.get(kind, ()):
                      self.index[kind].setdefault(rule[0], []).append(tuple(rule[1:]))

          def match(self, kind, argv):
              if not argv:
                  return False
              name = argv[0]
              if kind != "allow":
                  name = name.rsplit("/", 1)[-1]  # /bin/rm is rm for deny and ask, never for allow
              return any(tuple(argv[1:1 + len(tail)]) == tail for tail in self.index[kind].get(name, ()))

          def check_part(self, argv):
              argv = unwrap(list(argv))
              if not argv:
                  return "ask"
              for kind in ORDER:
                  if self.match(kind, argv):
                      return kind
              return "ask"

          def check(self, command):
              return self.check_part(command.split())
  - title: Split chains, refuse scripts
    brief: |
      Agents send chains. Split on && || ; | & and newlines, but only when the script is a chain of plain words, which is the line Codex draws before it evaluates parts separately. Remove quotes the way the shell does, because the gate and the shell must agree on where a string ends: inside single quotes a backslash is an ordinary character, and a gate that treats it as an escape reads echo 'a\' ; rm -rf x ; echo 'b\' as one echo. CVE-2025-54795 was a command-parsing error in this family, reached with a crafted echo. A script you will not split (substitution, redirection, globbing, control flow) is never allowed: deny it if a deny rule's words appear anywhere in it, otherwise ask. A shell started with -c is judged by its script and never allowed.
    starter: |
      def split_script(script):
          """The simple commands of a plain chain, each a list of words, or None when the gate should not split it.

          Split on && || ; | & and newlines outside quotes, removing quotes and backslashes as the shell does: inside
          single quotes nothing is special, a backslash included; inside double quotes a backslash escapes only " \\ $
          and a backtick. Return None for $ or a backtick outside single quotes, any of < > ( ) { } * ? [ outside
          quotes, a leading NAME=value, a control keyword in command position, an unclosed quote, or an operator with
          no command on one side.
          """
          raise NotImplementedError


      class Gate(Gate):
          def check(self, command):
              """The strictest decision over the parts of a plain chain. A script that is not split is never allowed:
              deny if a deny rule's words appear anywhere in it, otherwise ask. sh, bash, zsh or dash with -c is judged
              by its script and is never allowed either."""
              raise NotImplementedError

      def _chains(seed, n):
          import random
          rng = random.Random(seed)
          pool = ["git status", "npm test", "ls -la", "cat a.txt", "npm publish", "make", "rm x", "git push origin main",
                  "curl https://x.example", "echo hi"]
          ops = [" && ", " || ", "; ", " | ", " & ", "\n", ";"]
          for _ in range(n):
              parts = [rng.choice(pool) for _ in range(rng.randint(1, 6))]
              s = parts[0]

    solution: |
      import re

      UNSAFE = set("$`<>(){}*?[")
      CONTROL = {"if", "then", "else", "elif", "fi", "for", "while", "until", "do", "done", "case", "esac", "function", "!"}
      ASSIGN = re.compile(r"[A-Za-z_][A-Za-z0-9_]*=")
      SHELLS = {"sh", "bash", "zsh", "dash"}


      def split_script(s):
          """argv lists for a chain of plain commands joined by && || ; | & or newlines, else None."""
          parts, words, cur = [], [], []
          has_word, plain, after_op = False, True, False
          i, n = 0, len(s)

          def end_word():
              nonlocal cur, has_word
              if has_word:
                  words.append("".join(cur))
              cur, has_word = [], False

          while i < n:
              c = s[i]
              if c in " \t\r":
                  end_word()
                  i += 1
                  continue
              if c == "\\":
                  if i + 1 >= n:
                      return None
                  i += 2
                  if s[i - 1] == "\n":
                      continue  # a line continuation joins two lines
                  cur.append(s[i - 1])
              elif c == "'":
                  j = s.find("'", i + 1)  # inside single quotes a backslash is an ordinary character
                  if j < 0:
                      return None
                  cur.append(s[i + 1:j])
                  i = j + 1
              elif c == '"':
                  i += 1
                  while i < n and s[i] != '"':
                      if s[i] == "\\" and i + 1 < n and s[i + 1] in '"\\$`':
                          i += 1
                      elif s[i] in "$`":
                          plain = False
                      cur.append(s[i])
                      i += 1
                  if i >= n:
                      return None
                  i += 1
              elif s[i:i + 2] in ("&&", "||") or c in ";|&\n":
                  op = s[i:i + 2] if s[i:i + 2] in ("&&", "||") else c
                  end_word()
                  if words:
                      parts.append(words)
                      words = []
                  elif op != "\n":
                      return None  # an operator with no command before it
                  after_op = op != "\n"
                  i += len(op)
                  continue
              else:
                  if c in UNSAFE:
                      plain = False
                  cur.append(c)
                  i += 1
              has_word, after_op = True, False
          end_word()
          if words:
              parts.append(words)
          elif after_op:
              return None  # "npm test &&"
          if any(p[0] in CONTROL or ASSIGN.match(p[0]) for p in parts):
              plain = False
          return parts if plain else None


      class Gate(Gate):
          def scan(self, script):
              """A script we will not split: deny if a deny rule's words appear anywhere in it, else ask. Never allow."""
              text = script.replace("\\\n", "")
              for q in ("'", '"', "\\"):
                  text = text.replace(q, "")
              words = [w for w in re.split(r"[\s;&|()<>{}$`]+", text) if w]
              for k in range(len(words)):
                  if self.match("deny", words[k:]):
                      return "deny"
              return "ask"

          def decide_part(self, argv, depth=0):
              argv = unwrap(list(argv))
              if argv and argv[0].rsplit("/", 1)[-1] in SHELLS and "-c" in argv:
                  k = argv.index("-c") + 1
                  inner = argv[k] if k < len(argv) else ""
                  # A shell's -c script is checked for deny but never allowed: that would vouch for a second parse.
                  return "deny" if self.check(inner, depth + 1) == "deny" else "ask"
              return self.check_part(argv)

          def check(self, command, depth=0):
              parts = split_script(command)
              if parts is None or depth > 3:
                  return self.scan(command)
              return strictest([self.decide_part(p, depth) for p in parts]) if parts else "ask"
  - title: Protected paths no rule can approve
    brief: |
      Add the edit tool. Some paths change what the agent or the developer's tools will do next: git hooks, editor settings, MCP configuration, and the gate's own rules. No allow rule may approve an edit to them, and the check is on the name, so a file that does not exist yet is covered. CVE-2025-54135 was exactly that gap: Cursor asked before editing an existing dotfile and not before creating .cursor/mcp.json.     solution: |
      PROTECTED = frozenset({".git", ".gate", ".claude", ".cursor", ".codex", ".vscode", ".mcp.json",
                             ".bashrc", ".zshrc", ".profile", ".envrc"})
      READERS = {"cat", "ls", "head", "tail", "grep", "wc", "diff", "stat"}


      def covers(rule, path):
          return rule == "." or path == rule or path.startswith(rule.rstrip("/") + "/")


      class Gate(Gate):
          def __init__(self, rules, **options):
              super().__init__(rules, **options)
              self.protected = frozenset(options.get("protected", PROTECTED))
              self.edit_rules = options.get("edit_rules", {})

          def touches_protected(self, path):
              return any(c in self.protected for c in path.split("/"))

          def check_edit(self, path):
              if any(covers(r, path) for r in self.edit_rules.get("deny", ())):
                  return "deny"
              if self.touches_protected(path):
                  return "ask"  # checked before allow rules, so no allow rule can approve it
              if any(covers(r, path) for r in self.edit_rules.get("allow", ())):
                  return "allow"
              return "ask"

          def check_part(self, argv):
              decision = super().check_part(argv)
              args = unwrap(list(argv))
              if decision == "allow" and args and args[0] not in READERS:
                  if any(self.touches_protected(a) for a in args[1:] if not a.startswith("-")):
                      return "ask"
              return decision

          def check_call(self, call):
              if call.get("tool") == "edit":
                  return self.check_edit(call["path"])
              if call.get("tool") == "bash":
                  return self.check(call["command"])
              return "ask"
  - title: Normalise paths and follow symlinks
    brief: |
      Paths arrive as src/../.git/config, //workspace/.git/x and notes/pre-commit where notes is a symlink into .git/hooks.     starter: |
      class Gate(Gate):
          """Adds path normalisation and symlinks.

          Options: root, the workspace as an absolute path (default "/workspace"), and fs, the filesystem as
          {absolute path: "dir" | "file" | ("link", target)}, where a relative target is relative to the link's

              kernel would open (each symlink followed before the next ".." applies). Deny if the path never resolves.
              Never allow if either view is outside the workspace or passes through a protected name. Allow only if
              an allow rule covers both. Paths in shell arguments get the same protected-name check on both views."""

      def normalise(path):
          out = []
          for c in path.split("/"):
              if c == "..":
                  out = out[:-1]
              elif c not in ("", "."):
                  out.append(c)
          return "/" + "/".join(out)


      class Gate(Gate):
          def __init__(self, rules, **options):
              super().__init__(rules, **options)
              self.root = normalise(options.get("root", "/workspace"))
              self.fs = options.get("fs", {})

          def resolve(self, raw):
              """Follow symlinks one component at a time, as the kernel does. None after 40 hops."""
              todo = [c for c in reversed(raw.split("/")) if c not in ("", ".")]
              cur, hops = "/", 0
              while todo:
                  c = todo.pop()
                  if c == "..":
                      cur = cur.rsplit("/", 1)[0] or "/"
                      continue
                  nxt = cur.rstrip("/") + "/" + c
                  entry = self.fs.get(nxt)
                  if isinstance(entry, tuple):
                      hops += 1
                      if hops > 40:
                          return None
                      if entry[1].startswith("/"):
                          cur = "/"
                      todo.extend(x for x in reversed(entry[1].split("/")) if x not in ("", "."))
                  else:
                      cur = nxt
              return cur

          def locate(self, path):
              raw = path if path.startswith("/") else self.root + "/" + path
              return normalise(raw), self.resolve(raw)

          def rel(self, path):
              if path == self.root:
                  return "."
              if path.startswith(self.root + "/"):
                  return path[len(self.root) + 1:]
              return None  # outside the workspace: /workspace_evil is not inside /workspace

          def touches_protected(self, path):
              lexical, real = self.locate(path)
              return any(c in self.protected for p in (path, lexical, real or "") for c in p.split("/"))

              lexical, real = self.locate(path)
              if real is None:
                  return "deny"
              decisions = []
              for p in (lexical, real):
                  r = self.rel(p)
                  decisions.append("ask" if r is None else super().check_edit(r))
              return strictest(decisions)

      import hashlib
      import json


      def record_hash(record):
          body = {k: v for k, v in record.items() if k != "hash"}
          return hashlib.sha256(json.dumps(body, sort_keys=True).encode()).hexdigest()


      def verify(log):
          """True when every record's hash is right and each one points at the record before it."""
          prev = ""
          for n, rec in enumerate(log, 1):
              if rec.get("seq") != n or rec.get("prev") != prev or rec.get("hash") != record_hash(rec):
                  return False
              prev = rec["hash"]
          return True


      class Gate(Gate):
          def __init__(self, rules, **options):
              super().__init__(rules, **options)
              self.log = []

          def explain(self, call):
              if call.get("tool") == "edit":
                  lexical, real = self.locate(call["path"])
                  return {"path": lexical, "resolved": real}
              if call.get("tool") == "bash":
                  parts = split_script(call["command"])
                  if parts is None:
                      return {"split": False, "parts": []}
                  return {"split": True, "parts": [{"argv": p, "decision": self.decide_part(p)} for p in parts]}
              return {}

          def check_call(self, call):
              call = json.loads(json.dumps(call))  # a copy: the caller cannot change what was logged
              decision = super().check_call(call)
              rec = {"seq": len(self.log) + 1, "call": call, "decision": decision,
                     "detail": self.explain(call), "prev": self.log[-1]["hash"] if self.log else ""}
              rec["hash"] = record_hash(rec)
              self.log.append(rec)
              return decision

This lab builds the gate that sits between a coding agent and its tools, as one program. Each step adds to the same file and runs its tests against everything written so far, so the audit records in step 5 describe decisions made by the matcher from step 1, the splitter from step 2 and the path checks from steps 3 and 4.

The design follows what Claude Code and Codex document as of 2026-10-28: deny before ask before allow with specificity ignored, compound commands judged by their strictest part, scripts the gate cannot read never allowed, protected paths that no rule can approve, and symlinks judged at both ends. Each step's tests include bypasses modelled on a published CVE class: a parser that disagrees with the shell about quotes, an agent creating a config file that did not exist yet, an agent switching off its own approvals, and a workspace check that compared strings.

The filesystem in steps 4 and 5 is a dictionary, so every test is deterministic and runs in the browser. A real gate resolves against the disk at the moment of the check, and the file can change before the write; Claude Code's tools re-check the path when they open the file, and the sandbox, not the gate, is what stops a script that opens files itself. The gate decides when to involve a person. It is not the boundary.
