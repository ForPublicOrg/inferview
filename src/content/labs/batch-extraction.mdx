  - title: "A typed extraction schema and validator"
    brief: >-
      The validator is the contract between model output and the system of record, and everything later trusts it. It checks the schema (every field present, no unknown fields, non-empty strings, a real calendar date as YYYY-MM-DD, a known currency code, amounts that are numbers and not booleans) and one business rule: the lines add up to the total within one cent. Each error starts with the field it is about, so a review screen can highlight it. Its input is model output, so it never raises.

      import re
      from datetime import date

      FIELDS = ("vendor", "invoice_number", "invoice_date", "currency", "total", "lines")
      CURRENCIES = {"USD", "EUR", "GBP", "INR", "JPY"}
      DATE_RE = re.compile(r"^\d{4}-\d{2}-\d{2}$")


      def _amount(x):
          # bool is a subclass of int; x == x is False only for NaN; the bound rules out infinity
          return isinstance(x, (int, float)) and not isinstance(x, bool) and x == x and abs(x) < 1e15


      def validate(record):
          if not isinstance(record, dict):
              return ["record: expected an object"]
          errors = [f"{k}: unknown field" for k in record if k not in FIELDS]
          errors += [f"{k}: missing" for k in FIELDS if k not in record]
          for k in ("vendor", "invoice_number"):
              if k in record and not (isinstance(record[k], str) and record[k].strip()):
                  errors.append(f"{k}: expected a non-empty string")
          if "invoice_date" in record:
              d = record["invoice_date"]
              try:
                  if not (isinstance(d, str) and DATE_RE.match(d)):
                      raise ValueError
                  date.fromisoformat(d)
              except ValueError:
                  errors.append("invoice_date: expected a real date as YYYY-MM-DD")
          if "currency" in record and record["currency"] not in CURRENCIES:
              errors.append("currency: expected one of " + ", ".join(sorted(CURRENCIES)))
          total_ok = "total" in record and _amount(record["total"]) and record["total"] >= 0
          if "total" in record and not total_ok:
              errors.append("total: expected a non-negative number")
          lines = record.get("lines")
          lines_ok = isinstance(lines, list) and len(lines) > 0 and all(
              isinstance(l, dict) and set(l) == {"description", "amount"}
              and isinstance(l["description"], str) and l["description"].strip() and _amount(l["amount"])
              for l in lines
          )
          if "lines" in record and not lines_ok:
              errors.append("lines: expected a non-empty list of {description, amount}")
          if total_ok and lines_ok and abs(sum(l["amount"] for l in lines) - record["total"]) > 0.01 + 1e-9:
              errors.append("total: does not equal the sum of the lines")
          return errors
  - title: "A mock model with seeded errors"
    brief: >-
      The starter adds make_docs, which builds synthetic invoices, and MockModel, a deterministic stand-in for the extraction model. Which documents come back wrong is fixed by a hash of the document id, so every run sees the same errors. Some errors break the schema (a reply cut off at max_tokens, a misplaced decimal point, a date left in the document's own format) and some pass it (a dropped digit in the invoice number, two line descriptions swapped). Write parse_output and extract: one model call per document, and an outcome for every reply, however broken.
    starter: |

      VENDORS = ["Acme Tools", "Northwind Foods", "Globex Logistics", "Initech Office", "Umbrella Labs"]


      def make_docs(n, seed=1):
          """n synthetic invoices. The id has slashes, as many ERP document numbers do. Only the mock model and the
          tests read "truth"; your code reads the model's output."""
          rng = random.Random(seed)
          docs = []
          for i in range(n):
              lines = [{"description": f"Item {j + 1}", "amount": round(rng.uniform(5, 500), 2)} for j in range(rng.randint(1, 4))]
              truth = {"vendor": rng.choice(VENDORS), "invoice_number": f"INV-{100000 + i}",
                       "invoice_date": f"2026-{rng.randint(1, 9):02d}-{rng.randint(1, 28):02d}",
                       "currency": rng.choice(["USD", "EUR", "GBP"]),
                       "total": round(sum(l["amount"] for l in lines), 2), "lines": lines}
              text = f"{truth['vendor']}\nInvoice {truth['invoice_number']}\n" + "\n".join(f"{l['description']} {l['amount']:.2f}" for l in lines)
              docs.append({"id": f"AP/2026/{i:06d}", "text": text, "truth": truth})
          return docs


      class MockModel:
          """A deterministic stand-in for the extraction model. Which documents come back wrong is fixed by a hash of
          the seed and the document id, so every run sees the same errors. Some errors break the schema; some do not."""

          def __init__(self, seed=7):
              self.seed = seed
              self.calls = []

          def _roll(self, doc_id, salt):
              return random.Random(f"{self.seed}:{salt}:{doc_id}").random()

          def extract(self, doc):
              self.calls.append(("extract", doc["id"]))
              rec = json.loads(json.dumps(doc["truth"]))
              r = self._roll(doc["id"], "extract")
              if r < 0.04:
                  return json.dumps(rec)[:40]                          # output cut off at max_tokens
              if r < 0.10:
                  rec["total"] = round(rec["total"] * 10, 2)          # decimal point misread
              elif r < 0.15:
                  y, m, d = rec["invoice_date"].split("-")
                  rec["invoice_date"] = f"{d}/{m}/{y}"                # the document's own date format
              elif r < 0.22:
                  rec["invoice_number"] = rec["invoice_number"][:-1]  # a digit dropped; the schema cannot see it
              elif r < 0.27 and len(rec["lines"]) > 1:
                  a, b = rec["lines"][0], rec["lines"][1]
                  a["description"], b["description"] = b["description"], a["description"]  # also invisible to the schema
              return json.dumps(rec)


      def parse_output(doc_id, text):
          """Turn one model output into an outcome {"id", "status", "record", "errors"}. status is "ok" (passes
          validate), "invalid" (parsed, fails validate) or "unparseable"; record is None when unparseable. Never raise."""
          raise NotImplementedError


      def extract(model, doc):
          """One model call for one document, parsed with parse_output."""
          raise NotImplementedError

  - title: "A batch submitter that reconciles every document"
    brief: >-
      MockBatchAPI follows the shape of Claude's Message Batches API: a cap on requests and on bytes per batch, a limit on requests sitting in batches you have not collected, results in shuffled order, and succeeded, errored and expired outcomes. Document ids contain slashes, which the documented custom_id pattern rejects, so choose your own custom_id scheme and keep a map back. Pack batches by count and by bytes, collect before the queue overflows, join results on custom_id, re-send expired requests and api_error failures up to max_rounds attempts in all, and treat invalid_request_error as final. A document too large for any batch becomes an outcome, not an exception. The tests check that every document ends with exactly one outcome joined to the right document.
    starter: |
      import re


      class MockBatchAPI:
          """A stand-in for a provider batch endpoint, shaped like Claude's Message Batches API. A batch holds at most
          max_requests requests and max_bytes of JSON (len(json.dumps(request)) summed over its requests), and at most
          max_queued requests may sit in batches whose results you have not collected. results() returns each request's
          result once, in shuffled order. A seeded share of requests expire or fail with a retryable api_error; a
          document marked "poison" fails with invalid_request_error every time. A request is {"custom_id", "doc"}."""
          ID_RE = re.compile(r"^[a-zA-Z0-9_-]{1,64}$")

          def __init__(self, model, max_requests=100_000, max_bytes=256_000_000, max_queued=300_000, seed=11):
              self.model, self.seed = model, seed
              self.max_requests, self.max_bytes, self.max_queued = max_requests, max_bytes, max_queued
              self.pending, self.sizes, self.attempts = {}, [], {}

          def create(self, requests):
              ids = [r["custom_id"] for r in requests]
              if not requests or len(requests) > self.max_requests:
                  raise ValueError(f"a batch holds 1 to {self.max_requests} requests, got {len(requests)}")
              if sum(len(json.dumps(r)) for r in requests) > self.max_bytes:
                  raise ValueError("batch is larger than max_bytes")
              if len(set(ids)) != len(ids) or not all(self.ID_RE.match(i) for i in ids):
                  raise ValueError("custom_id values must be unique and match ^[a-zA-Z0-9_-]{1,64}$")
              if sum(map(len, self.pending.values())) + len(requests) > self.max_queued:
                  raise RuntimeError("429: processing queue is full; collect results first")
              batch_id = f"msgbatch_{len(self.sizes) + 1:04d}"
              self.pending[batch_id] = requests
              self.sizes.append(len(requests))
              return batch_id

          def results(self, batch_id):
              out = []
              for req in self.pending.pop(batch_id):
                  doc = req["doc"]
                  n = self.attempts[doc["id"]] = self.attempts.get(doc["id"], 0) + 1
                  roll = random.Random(f"{self.seed}:{doc['id']}:{n}").random()
                  if doc.get("poison"):
                      res = {"type": "errored", "error": {"type": "invalid_request_error"}}
                  elif roll < 0.08:
                      res = {"type": "expired"}
                  elif roll < 0.11:
                      res = {"type": "errored", "error": {"type": "api_error"}}
                  else:
                      text = self.model.extract(doc)
                      res = {"type": "succeeded", "text": text,
                             "usage": {"input_tokens": 900 + len(doc["text"]) // 4, "output_tokens": len(text) // 4}}
                  out.append({"custom_id": req["custom_id"], "result": res})
              random.Random(f"{self.seed}:{batch_id}").shuffle(out)
              return out


      def run_batches(api, docs, max_rounds=3):
          """Send every document through api and return {doc_id: outcome} with exactly one outcome per document.
          A succeeded result becomes parse_output's outcome plus "usage". An expired request or an api_error is sent
          again in a later round, up to max_rounds attempts in all; invalid_request_error is final. A document still
          unresolved at the end keeps status "expired" or "errored". Every outcome carries "attempts". Stay inside
          api.max_requests, api.max_bytes and api.max_queued."""
          raise NotImplementedError
    tests: |

      assert all(out[d["id"]]["record"] == json.loads(MockModel().extract(d)) for d in docs if out[d["id"]]["status"] in ("ok", "invalid")), "results are joined to the right document"
      assert any(o["attempts"] > 1 and o["status"] == "ok" for o in out.values()), "expired and api_error requests are sent again"

      def _failed(doc_id, status, kind):
          return {"id": doc_id, "status": status, "record": None, "errors": [kind]}


      def _batches(api, cids, by_cid, outcomes):
          """Pack requests under every cap. A request too big for any batch is resolved here instead of crashing the run."""
          cap = min(api.max_requests, api.max_queued)
          batch, size = [], 0
          for cid in cids:
              req = {"custom_id": cid, "doc": by_cid[cid]}
              n = len(json.dumps(req))
              if n > api.max_bytes:
                  outcomes[by_cid[cid]["id"]] = {**_failed(by_cid[cid]["id"], "errored", "request_too_large"), "attempts": 0}
                  continue
              if batch and (len(batch) == cap or size + n > api.max_bytes):
                  yield batch
                  batch, size = [], 0
              batch.append(req)
              size += n
          if batch:
              yield batch


      def run_batches(api, docs, max_rounds=3):
          # custom_id is our own key: document ids can break the provider's pattern, so keep a map back to them.
          by_cid = {f"d{i}": doc for i, doc in enumerate(docs)}
          tries = dict.fromkeys(by_cid, 0)
          outcomes, todo = {}, list(by_cid)
          for _ in range(max_rounds):
              again, pending = [], []

              def collect():
                  for batch_id in pending:
                      for item in api.results(batch_id):
                          cid, res = item["custom_id"], item["result"]
                          doc_id = by_cid[cid]["id"]
                          tries[cid] += 1
                          if res["type"] == "succeeded":
                              out = {**parse_output(doc_id, res["text"]), "usage": res["usage"]}
                          else:
                              kind = res.get("error", {}).get("type", res["type"])
                              out = _failed(doc_id, "expired" if res["type"] == "expired" else "errored", kind)
                              if kind in ("expired", "api_error"):
                                  again.append(cid)
                          out["attempts"] = tries[cid]
                          outcomes[doc_id] = out
                  pending.clear()

              queued = 0
              for batch in _batches(api, todo, by_cid, outcomes):
                  if queued + len(batch) > api.max_queued:
                      collect()
                      queued = 0
                  pending.append(api.create(batch))
                  queued += len(batch)
              collect()
              todo = again
          return outcomes

      class VerifyingModel(MockModel):
          """Adds the second call: given the document and an extracted record, answer yes or no to "is this record
          correct?". Like a real API it returns only the top few first-token log probabilities, with case and spacing
          variants as separate tokens, and sometimes the first token is neither yes nor no. Correct records tend to
          score higher, but the two populations overlap."""

          def verify(self, doc, record):
              self.calls.append(("verify", doc["id"]))
              r = self._roll(doc["id"], "verify")

              top = {"Yes": math.log(p * 0.8), " yes": math.log(p * 0.2), "No": math.log((1 - p) * 0.9), "The": math.log((1 - p) * 0.1)}
              if r > 0.97:
                  top = {"The": math.log(0.6), "Based": math.log(0.3)}
              return {"top_logprobs": top, "usage": {"input_tokens": 700 + len(doc["text"]) // 4, "output_tokens": 1}}


      def _logsumexp(xs):
          m = max(xs)
          return m + math.log(sum(math.exp(x - m) for x in xs))


      def p_yes(top_logprobs):
          yes = [lp for tok, lp in top_logprobs.items() if tok.strip().lower() == "yes"]
          no = [lp for tok, lp in top_logprobs.items() if tok.strip().lower() == "no"]
          if not yes:
              return 0.0
          if not no:
              return 1.0
          # p = Y / (Y + N) computed in log space, so tiny probabilities do not underflow to 0 / 0
          return 1.0 / (1.0 + math.exp(_logsumexp(no) - _logsumexp(yes)))


      def score(model, doc, outcome):
          if outcome["status"] != "ok":
              return 0.0
          reply = model.verify(doc, outcome["record"])
          outcome["verify_usage"] = reply["usage"]
          return p_yes(reply["top_logprobs"])

      def choose_threshold(sample, max_error):
          # One sort, one sweep from the most confident down; a threshold is only checked at the end of a run of ties.
          ranked = sorted(sample, key=lambda p: -p[0])
          best, accepted, errors = float("inf"), 0, 0
          for i, (conf, correct) in enumerate(ranked):
              accepted += 1
              errors += not correct
              last_of_tie = i + 1 == len(ranked) or ranked[i + 1][0] != conf
              if last_of_tie and errors <= max_error * accepted + 1e-12:
                  best = conf
          return best


      def route(items, t):
          auto = [doc_id for doc_id, conf in items if conf >= t]
          review = [doc_id for doc_id, conf in items if conf < t]
          return auto, review


      def reviewer_hours(n_review, seconds_each):
          return n_review * seconds_each / 3600
