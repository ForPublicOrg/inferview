  - title: Scheme allowlist
    brief: |
      The fetch tool takes URLs the model wrote, often copied from a page an attacker controls. Before anything resolves, parse the URL into a Target and refuse what the gate does not speak: any scheme but http and https, and any scheme the deployment did not list. The MCP security page (revision 2026-07-28) has clients require https for the URLs a server hands them, except loopback during development behind an explicit opt-out, and reject javascript:, data:, file: and vbscript: URLs; the same rules suit a fetch tool, and Policy.dev_loopback is the opt-out. Refuse userinfo, a backslash and control characters, because parsers disagree about where such a URL points. Normalise the host (lowercase, no trailing dot, no IPv6 brackets) so later steps compare one spelling. Anything malformed raises Denied and never another exception: the agent gets the reason as a tool result, and a crash in the gate is a crash in the tool.

      from collections import namedtuple
      from urllib.parse import urlsplit

      Target = namedtuple("Target", "scheme host port url")

      DEFAULT_PORTS = {"https": 443, "http": 80}
      LOOPBACK_NAMES = {"localhost", "127.0.0.1", "::1"}


      class Denied(Exception):
          """The gate refused the request. str(e) is the reason the agent sees."""


      class Policy:
          """schemes: the schemes the deployment allows. hosts: the allowlist (step 2).
          dev_loopback: a local development opt-out that lets http reach loopback and nothing else."""

          def __init__(self, schemes=("https",), hosts=(), dev_loopback=False):
              self.schemes = {s.lower() for s in schemes}
              self.hosts = list(hosts)
              self.dev_loopback = dev_loopback


      def parse_target(url, policy):
          if not isinstance(url, str) or not url:
              raise Denied("no URL")
          # Clients disagree about where a URL with a backslash or a control character points, so refuse it.
          if "\\" in url or any(ord(c) < 33 or ord(c) == 127 for c in url):
              raise Denied("malformed URL")
          try:
              parts = urlsplit(url)
              port = parts.port
          except ValueError:
              raise Denied("malformed URL or port")
          scheme = parts.scheme.lower()
          if scheme not in DEFAULT_PORTS or scheme not in policy.schemes:
              raise Denied("scheme not allowed: " + (scheme or "none"))
          if "@" in parts.netloc:
              raise Denied("userinfo in URL")
          host = (parts.hostname or "").rstrip(".")
          if not host:
              raise Denied("no host")
          if scheme == "http" and not (policy.dev_loopback and host in LOOPBACK_NAMES):
              raise Denied("http is allowed only to loopback in development")
          return Target(scheme, host, port if port is not None else DEFAULT_PORTS[scheme], url)
  - title: Host allowlist
    brief: |
      The allowlist has exact names, "*.suffix" entries that match any name under the suffix at any depth but never the suffix itself, and IP entries compared as addresses, so 2606:4700:0:0::1111 matches 2606:4700::1111. A bare "*" is refused when the policy is built, because it turns the allowlist off. In this scenario the list is generated from every tenant's configured mirrors and webhooks and runs to hundreds of thousands of entries, and the gate runs on every fetch, so build an index once in __init__ instead of walking the list per call; the hidden test times lookups against 200,000 entries. Match suffixes at label boundaries, or evilgithubusercontent.com passes as a githubusercontent.com host.

      import ipaddress


      def _as_address(text):
          """The address a host or entry names, or None for a name. Cheap for names, which are most entries."""
          if ":" not in text and not text.replace(".", "").isdigit():
              return None
          try:
              return ipaddress.ip_address(text.strip("[]"))
          except ValueError:
              return None


      class Policy(Policy):
          def __init__(self, schemes=("https",), hosts=(), dev_loopback=False):
              super().__init__(schemes, hosts, dev_loopback)
              self.exact, self.suffixes, self.addresses = set(), set(), set()
              for entry in self.hosts:
                  e = entry.strip().lower().rstrip(".")
                  if e == "*" or e == "*.":
                      raise ValueError("a bare * turns the allowlist off; list the hosts")
                  if e.startswith("*."):
                      self.suffixes.add(e[2:])
                      continue
                  address = _as_address(e)
                  if address is not None:
                      self.addresses.add(address)
                  else:
                      self.exact.add(e)

          def allows_host(self, host):
              h = host.lower().rstrip(".")
              if self.dev_loopback and h in LOOPBACK_NAMES:
                  return True
              address = _as_address(h)
              if address is not None:
                  return address in self.addresses
              if h in self.exact:
                  return True
              # One set probe per label, so the cost does not grow with the size of the allowlist.
              i = h.find(".")
              while i != -1:
                  if h[i + 1:] in self.suffixes:
                      return True
                  i = h.find(".", i + 1)
              return False


      def check_target(url, policy):
          target = parse_target(url, policy)
          if not policy.allows_host(target.host):
              raise Denied("host not allowed: " + target.host)
          return target
  - title: Resolve then pin to defeat DNS rebinding
    brief: |
      A check that resolves the name and a client that resolves it again are two lookups, and a rebinding server answers them differently: a public address for the check, 169.254.169.254 for the connection. Resolve once, check every address in the answer, and hand the first one to the transport, which connects to that address and sends the name only as the Host header and TLS name. The MCP page names this time-of-check to time-of-use gap and suggests pinning; Codex's documentation says its own DNS check reduces rebinding risk but does not eliminate it. Refuse the whole answer if any address fails rather than filtering it: a mixed answer is what a rebinding setup looks like, at the cost of refusing hosts with split-horizon DNS. An IP literal is not looked up. FakeDNS plays the attacker's resolver; address_allowed stays a stub that refuses non-addresses until the next step.
    starter: |
      def _numeric_name(name):
          """What getaddrinfo makes of a numeric name: 1 to 4 parts, each decimal, 0x hex or 0-led octal."""
          parts = name.split(".")
          if not 1 <= len(parts) <= 4:
              return None
          vals = []
          for p in parts:
              try:
                  if p.lower().startswith("0x"):
                      v = int(p[2:] or "0", 16)
                  elif len(p) > 1 and p.startswith("0"):
                      v = int(p, 8)
                  else:
                      v = int(p, 10)
              except ValueError:
                  return None
              vals.append(v)
          *head, last = vals
          if any(v > 255 for v in head) or last >= 256 ** (4 - len(head)):
              return None
          n = 0
          for v in head:
              n = n * 256 + v
          n = (n << (8 * (4 - len(head)))) | last
          return ".".join(str((n >> s) & 255) for s in (24, 16, 8, 0))


      class FakeDNS:
          """A scripted resolver standing in for the attacker's DNS server. answers maps a name to a list of
          answers (each a list of address strings); lookup k returns answer k and the last one repeats, which
          is how a rebinding server behaves. A name not in the table resolves the way getaddrinfo resolves a
          numeric name, or raises LookupError. Every lookup is logged in calls."""

          def __init__(self, answers):
              self.answers = {k.lower(): [list(a) for a in v] for k, v in answers.items()}
              self.calls = []

          def resolve(self, name):
              n = name.lower().rstrip(".")
              self.calls.append(n)
              if n in self.answers:
                  seq = self.answers[n]
                  k = sum(1 for c in self.calls if c == n) - 1
                  return list(seq[min(k, len(seq) - 1)])
              numeric = _numeric_name(n)
              if numeric is None:
                  raise LookupError(name)
              return [numeric]


      class FakeResponse:
          """A response whose body arrives in chunks. pulled counts the chunks read so far."""

          def __init__(self, status=200, headers=None, chunks=(b"ok",)):
              self.status = status
              self.headers = {k.lower(): v for k, v in (headers or {}).items()}
              self._chunks = chunks
              self.pulled = 0

          def iter_chunks(self):
              for c in self._chunks:
                  self.pulled += 1
                  yield c


      class FakeTransport:
          """One HTTP exchange per request(address, target, headers): connect to address, send target.host as the
          Host header and TLS name, never follow redirects. routes maps a URL to a FakeResponse or to a function
          of the request number that returns one. Every request is logged in sent as (address, target, headers)."""

          def __init__(self, routes=None):
              self.routes = routes or {}
              self.sent = []

          def request(self, address, target, headers):
              self.sent.append((address, target, dict(headers)))
              r = self.routes.get(target.url)
              if callable(r):
                  r = r(len(self.sent))
              return r if r is not None else FakeResponse()

      import zlib


      def read_body(response, max_bytes=1_000_000):
          declared = response.headers.get("content-length")
          if declared is not None:
              if not str(declared).strip().isdigit():
                  raise Denied("bad content-length")
              if int(declared) > max_bytes:
                  raise Denied("declared body over the limit")
          encoding = response.headers.get("content-encoding", "identity").strip().lower()
          if encoding not in ("identity", "gzip"):
              raise Denied("unsupported content-encoding: " + encoding)
          inflate = zlib.decompressobj(16 + zlib.MAX_WBITS) if encoding == "gzip" else None
          out, size = [], 0

          def take(piece):
              nonlocal size
              size += len(piece)
              if size > max_bytes:
                  raise Denied("body over %d bytes" % max_bytes)
              out.append(piece)

          for chunk in response.iter_chunks():
              if inflate is None:
                  take(chunk)
                  continue
              data = chunk
              while data:
                  # max_length caps each step, so a few compressed bytes cannot expand past the limit in memory.
                  take(inflate.decompress(data, max_bytes - size + 1))
                  data = inflate.unconsumed_tail
          if inflate is not None:
              take(inflate.flush())
          return b"".join(out)


      def fetch(url, policy, dns, transport, headers=None, max_redirects=5, max_bytes=1_000_000):
          final, response = follow(url, policy, dns, transport, headers, max_redirects)
          return Result(final, response.status, response.headers, read_body(response, max_bytes))

This lab builds the gate that sits between an agent's fetch tool and the network, as one program. Each step adds to the same file and runs its tests against everything you have written so far, so step 6 still depends on the parser from step 1 and the address rule from step 4.

The tests come from the server-side request forgery list in the MCP specification's security page: internal addresses written directly, the cloud metadata endpoint, localhost services, DNS rebinding and redirect chains, plus the octal, hex and IPv4-mapped spellings the page warns about. Nothing touches a real network. FakeDNS answers from a script the way an attacker's DNS server would, including a different answer on the second lookup, and resolves numeric names the way getaddrinfo does. FakeTransport records which address each request went to and never follows a redirect. The tests assert behaviour: lookups made, addresses connected to, headers sent, chunks read.

Where the gate runs matters as much as what it checks. If the agent can open a socket itself, from a shell command or a script, the gate is advice: the request never calls it. In production it belongs outside the agent's sandbox as the only route out: Claude Code's sandbox gives commands no direct route out except its proxy, and the MCP page recommends egress proxies such as Smokescreen for server-side clients. Two limits remain after the last step. A policy keyed on host names cannot see what a request carries, so an allowed host that accepts uploads is still a way out for data. And a proxy that decides from the client-supplied host name without terminating TLS, as Claude Code's documentation says of its own, can be steered by domain fronting.
