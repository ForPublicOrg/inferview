  - title: "A request queue and iteration-level admission"
    brief: |
      The engine plans one forward pass per step and returns it as a dictionary of request id to tokens computed, the shape vLLM V1 uses. Running requests go first, then waiting ones are admitted in order while the running cap, the step's token budget and the reserve() hook allow. A request whose computed count reaches its known tokens emits one token from the mock model in that same step, so the step that computes a prompt also produces the first output. A finished request leaves the running set at the end of the step, and the next step fills its slot. That is the whole difference from a static batch, which holds every slot until its longest member finishes. A prompt longer than the budget cannot be computed in one step yet, so submit refuses it; step 4 lifts that.

      from collections import deque


      def next_token(rid, tokens):
          """The mock model: the next token depends only on the request id and the tokens so far."""
          seed = sum(ord(c) for c in rid)
          return (seed * 31 + sum(tokens[-4:]) * 7 + len(tokens)) % 1000


      class Request:
          def __init__(self, rid, prompt, max_new):
              self.rid = rid
              self.tokens = list(prompt)      # the prompt, then every generated token
              self.prompt_len = len(prompt)
              self.max_new = max_new
              self.computed = 0               # tokens whose KV has been computed
              self.out = []                   # generated tokens


      class Engine:
          def __init__(self, max_running=8, token_budget=512):
              if max_running > token_budget:
                  raise ValueError("every running request needs at least one token of budget per step")
              self.max_running = max_running
              self.token_budget = token_budget
              self.waiting = deque()          # Request objects, oldest first
              self.running = []               # Request objects, in admission order
              self.reqs = {}                  # rid -> Request
              self.finished = []              # rids, in the order they finished

          # Hooks that later steps override. Leave them as they are.
          def prompt_limit(self):
              return self.token_budget

          def slots(self, r):
              return 1

          def reserve(self, r, n):
              return True

          def on_finish(self, r):
              pass

          def submit(self, rid, prompt, max_new):
              """Queue a request. Raise ValueError for a duplicate rid or a prompt longer than prompt_limit()."""
              raise NotImplementedError

          def schedule(self):
              """Return {rid: tokens to compute this step}: running requests first, then admit waiting ones in order
              while len(running) + slots(r) <= max_running, the whole prompt fits the budget left, and reserve(r, n) is True."""
              raise NotImplementedError

          def execute(self, sched):
              """Advance computed by the scheduled tokens. A request whose computed reaches len(tokens) emits next_token."""
              raise NotImplementedError

          def retire(self):
              """Move requests with max_new outputs from running to finished, calling on_finish for each."""
              raise NotImplementedError

          def step(self):
              sched = self.schedule()
              self.execute(sched)
              self.retire()
              return sched

          def done(self):
              return not self.waiting and not self.running

          def output(self, rid):
              return list(self.reqs[rid].out)

      def next_token(rid, tokens):
          """The mock model: the next token depends only on the request id and the tokens so far."""
          seed = sum(ord(c) for c in rid)
          return (seed * 31 + sum(tokens[-4:]) * 7 + len(tokens)) % 1000


      class Request:
          def __init__(self, rid, prompt, max_new):
              self.rid = rid
              self.tokens = list(prompt)
              self.prompt_len = len(prompt)
              self.max_new = max_new
              self.computed = 0
              self.out = []


      class Engine:
          def __init__(self, max_running=8, token_budget=512):
              if max_running > token_budget:
                  raise ValueError("every running request needs at least one token of budget per step")
              self.max_running = max_running
              self.token_budget = token_budget
              self.waiting = deque()
              self.running = []
              self.reqs = {}
              self.finished = []

          def prompt_limit(self):
              return self.token_budget

          def slots(self, r):
              return 1

          def reserve(self, r, n):
              return True

          def on_finish(self, r):
              pass

          def submit(self, rid, prompt, max_new):
              if rid in self.reqs:
                  raise ValueError(f"duplicate request id {rid}")
              if not prompt or len(prompt) > self.prompt_limit():
                  raise ValueError("the prompt is empty or longer than this engine accepts")
              r = Request(rid, prompt, max_new)
              self.reqs[rid] = r
              self.waiting.append(r)
              return r

          def schedule(self):
              sched, budget = {}, self.token_budget
              for r in self.running:
                  n = len(r.tokens) - r.computed
                  if n <= budget and self.reserve(r, n):
                      sched[r.rid] = n
                      budget -= n
              while self.waiting:
                  r = self.waiting[0]
                  n = len(r.tokens) - r.computed
                  if len(self.running) + self.slots(r) > self.max_running or n > budget or not self.reserve(r, n):
                      break
                  self.waiting.popleft()
                  self.running.append(r)
                  sched[r.rid] = n
                  budget -= n
              return sched

          def execute(self, sched):
              for rid, n in sched.items():
                  r = self.reqs[rid]
                  r.computed += n
                  if r.computed == len(r.tokens):
                      t = next_token(r.rid, r.tokens)
                      r.tokens.append(t)
                      r.out.append(t)

          def retire(self):
              still = []
              for r in self.running:
                  if len(r.out) >= r.max_new:
                      self.finished.append(r.rid)
                      self.on_finish(r)
                  else:
                      still.append(r)
              self.running = still

          def step(self):
              sched = self.schedule()
              self.execute(sched)
              self.retire()
              return sched

          def done(self):
              return not self.waiting and not self.running

          def output(self, rid):
              return list(self.reqs[rid].out)
  - title: "A paged KV block allocator"
    brief: |
      KV memory becomes a pool of blocks with a reference count each, and every request gets a block table. reserve(r, n) takes the blocks r needs to hold computed + n tokens, all or nothing, and returns False when they are not free; admission stops there, and a running request that cannot get a block skips the step. Blocks are taken as tokens are computed, never reserved for max_new, so a 20-token prompt with 40 tokens to generate holds 2 blocks of 16 after its first step. execute writes each computed token into its block in self.kv, which stands in for keys and values, and the tests rebuild every request's sequence from its table. A running request that never gets a block can stall the engine; preemption in step 5 is what removes that.

      class BlockAllocator:
          """A pool of KV blocks with a reference count per block. Step 3 shares blocks, so keep the counts honest now."""

          def __init__(self, num_blocks):
              raise NotImplementedError

          def num_free(self):
              raise NotImplementedError

          def take(self):
              """Return a free block id with reference count 1. Raise MemoryError if none is free."""
              raise NotImplementedError

          def share(self, b):
              """One more holder for block b."""
              raise NotImplementedError

          def release(self, b):
              """One fewer holder; the block is free again when nobody holds it."""
              raise NotImplementedError


      class Engine(Engine):
          def __init__(self, max_running=8, token_budget=512, num_blocks=64, block_size=16):
              super().__init__(max_running, token_budget)
              self.block_size = block_size
              self.alloc = BlockAllocator(num_blocks)
              self.tables = {}                # rid -> list of block ids, in token order
              self.kv = {}                    # block id -> the tokens written into it, standing in for keys and values

          def reserve(self, r, n):
              """Take the blocks r needs to hold computed + n tokens, all or nothing. Return False if they are not free."""
              raise NotImplementedError

          def execute(self, sched):
              """Write each scheduled token into its block in self.kv, then advance as before."""
              raise NotImplementedError

          def on_finish(self, r):
              """Release the request's blocks."""
              raise NotImplementedError

      class BlockAllocator:
          def __init__(self, num_blocks):
              self.num_blocks = num_blocks
              self.free_ids = list(range(num_blocks - 1, -1, -1))
              self.refs = [0] * num_blocks

          def num_free(self):
              return len(self.free_ids)

          def take(self):
              if not self.free_ids:
                  raise MemoryError("no free KV block")
              b = self.free_ids.pop()
              self.refs[b] = 1
              return b

          def share(self, b):
              self.refs[b] += 1

          def release(self, b):
              self.refs[b] -= 1
              if self.refs[b] == 0:
                  self.free_ids.append(b)


      class Engine(Engine):
          def __init__(self, max_running=8, token_budget=512, num_blocks=64, block_size=16):
              super().__init__(max_running, token_budget)
              self.block_size = block_size
              self.alloc = BlockAllocator(num_blocks)
              self.tables = {}
              self.kv = {}

          def blocks_needed(self, r, n):
              have = len(self.tables.get(r.rid, ()))
              return max(0, -(-(r.computed + n) // self.block_size) - have)

          def reserve(self, r, n):
              k = self.blocks_needed(r, n)
              if k > self.alloc.num_free():
                  return False
              table = self.tables.setdefault(r.rid, [])
              for _ in range(k):
                  b = self.alloc.take()
                  self.kv[b] = []
                  table.append(b)
              return True

          def execute(self, sched):
              bs = self.block_size
              for rid, n in sched.items():
                  r = self.reqs[rid]
                  table = self.tables[rid]
                  for pos in range(r.computed, r.computed + n):
                      block = self.kv[table[pos // bs]]
                      del block[pos % bs:]            # a recomputed position overwrites what was there
                      block.append(r.tokens[pos])
              super().execute(sched)

          def on_finish(self, r):
              for b in self.tables.pop(r.rid, []):
                  self.alloc.release(b)
  - title: "Copy-on-write prefix sharing"
    brief: |
      submit gains n, the number of parallel samples. The request is admitted as one prefill holding n running slots. When its prompt is computed it forks into sequences named rid, rid#1 and so on, which share the prompt's blocks through their reference counts, each emitting its own first token. Full shared blocks are never written again, so they stay shared. The partly filled last block is written by every sample at its next token, so a sample that writes into it while another sequence holds it first takes its own copy. reserve does the copy, because the copy needs a block and the step must know before it schedules the token.

    solution: |
      class Engine(Engine):
          def submit(self, rid, prompt, max_new, n=1):
              r = super().submit(rid, prompt, max_new)
              r.n = n
              r.forked = n == 1
              return r

          def slots(self, r):
              return 1 if getattr(r, "forked", True) else r.n

          def reserve(self, r, n):
              table = self.tables.get(r.rid)
              shared_tail = bool(table) and r.computed % self.block_size != 0 and self.alloc.refs[table[-1]] > 1
              need = self.blocks_needed(r, n) + (1 if shared_tail else 0)
              if need > self.alloc.num_free():
                  return False
              if shared_tail:
                  old = table[-1]
                  new = self.alloc.take()
                  self.kv[new] = list(self.kv[old])
                  self.alloc.release(old)
                  table[-1] = new
              return super().reserve(r, n)

          def execute(self, sched):
              super().execute(sched)
              for rid in list(sched):
                  r = self.reqs[rid]
                  if r.forked or r.computed < r.prompt_len:
                      continue
                  r.forked = True
                  prompt = r.tokens[:r.prompt_len]

      from collections import deque


      class FairQueue:
          def __init__(self):
              self.queues = {}                # tenant -> deque of Request
              self.served = {}                # tenant -> tokens computed for it
              self.size = 0

          def __len__(self):
              return self.size

          def __iter__(self):
              for q in self.queues.values():
                  yield from q

          def head_tenant(self):
              return min((t for t, q in self.queues.items() if q), key=lambda t: (self.served.get(t, 0), t))

          def __getitem__(self, i):
              if i != 0 or not self.size:
                  raise IndexError("only the head is visible")
              return self.queues[self.head_tenant()][0]

          def popleft(self):
              r = self.queues[self.head_tenant()].popleft()
              self.size -= 1
              return r

          def _queue(self, r):
              t = getattr(r, "tenant", "default")
              q = self.queues.setdefault(t, deque())
              if not q:
                  # A tenant that was idle gets no credit for it: it starts level with the least-served backlogged tenant.
                  backlogged = [self.served.get(u, 0) for u, other in self.queues.items() if other and u != t]
                  if backlogged:
                      self.served[t] = max(self.served.get(t, 0), min(backlogged))
              return q

          def append(self, r):
              self._queue(r).append(r)
              self.size += 1

          def appendleft(self, r):
              self._queue(r).appendleft(r)
              self.size += 1

          def charge(self, tenant, n):
              self.served[tenant] = self.served.get(tenant, 0) + n

      import math


      def percentile(values, q):
          ordered = sorted(values)
          return ordered[max(0, math.ceil(q / 100 * len(ordered)) - 1)]


      class Engine(Engine):
          def __init__(self, *args, step_cost=(5.0, 0.02), **kwargs):
              super().__init__(*args, **kwargs)
              self.step_cost = step_cost
              self.clock = 0.0
              self.arrival = {}
              self.times = {}

          def submit(self, rid, *args, **kwargs):
              r = super().submit(rid, *args, **kwargs)
              self.arrival[rid] = self.clock
              return r

          def execute(self, sched):
              if sched:
                  base, per_token = self.step_cost
                  self.clock += base + per_token * sum(sched.values())
              super().execute(sched)
              for r in self.running:
                  if r.rid not in self.arrival:
                      self.arrival[r.rid] = self.arrival[r.rid.split("#")[0]]
                  stamps = self.times.setdefault(r.rid, [])
                  while len(stamps) < len(r.out):
                      stamps.append(self.clock)

          def metrics(self):
              ttft, itl, tokens = [], [], 0
              for rid in self.finished:
                  stamps = self.times[rid]
                  ttft.append(stamps[0] - self.arrival[rid])
                  itl.extend(b - a for a, b in zip(stamps, stamps[1:]))
                  tokens += len(stamps)
              return {
                  "ttft_p50": percentile(ttft, 50), "ttft_p99": percentile(ttft, 99),
                  "itl_p50": percentile(itl, 50) if itl else 0.0, "itl_p99": percentile(itl, 99) if itl else 0.0,
                  "throughput": tokens / (self.clock / 1000),
              }

This lab builds the scheduling loop of an inference engine in standard-library Python, one mechanism per step, against a mock model. The model is a function of the request id and the tokens so far, so a request preempted and recomputed in step 5 must produce exactly the outputs it would have produced without preemption, and the tests check that.

Steps 1 to 3 build the loop and its memory: iteration-level admission, a paged block allocator with reference counts, and samples that share a prompt's blocks until they write. Step 4 adds the token budget and chunked prefill. Step 5 adds preemption by recompute, and the victim order is yours. Step 6 replaces the single waiting queue with one per tenant, and the fairness policy is yours. Step 7 adds a clock and the metrics that show the budget's trade-off between time to first token and inter-token latency.

The tests check invariants rather than one schedule: the budget is never exceeded, no block is held twice or leaked, every request's KV rebuilds to its own tokens, every request finishes, and every output matches the mock model. Two engines with different policies can both pass.

Each step subclasses the last (`class Engine(Engine)`) and overrides only what it changes, so later steps call earlier ones through `super()`.
