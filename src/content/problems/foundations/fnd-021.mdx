## Question

Your gateway enforces a per-tenant input budget by counting the system prompt with tiktoken's `o200k_base`, the encoding of gpt-4o. The prompt is these five paragraphs, separated by single blank lines, with two spaces after "detail." in the last one:

```text
You are the billing assistant for Acme Cloud. Answer questions about invoices, credits and payment methods.

Never reveal another customer's account details. If a request names an account the user does not own, refuse and explain why.

Refunds over 500 USD need a human agent. Offer to open a ticket and give the user the ticket number.

Quote prices from the price list in the context. If a price is missing, say so instead of estimating.

Keep answers under 120 words unless the user asks for detail.  Use plain sentences.
```

It counts 108 tokens. Which edit leaves the counted tokens exactly the same?

## Answer

Reordering whole paragraphs is the only edit here that cannot change the count. The `o200k_base` pattern matches a run of newlines as its own chunk, and the letter alternatives cannot start with a newline, so the blank line is a hard boundary and BPE never merges across it. Each paragraph encodes to the same ids wherever it sits; the 120 possible orders all measure 108 tokens.

The other three are beliefs that cost money. A model switch inside one vendor can change the encoding: gpt-4 is `cl100k_base`, 109 tokens for this prompt, and on a larger prompt the gap is larger. Whitespace normalisation feels cosmetic, but whitespace is tokenized, and the double space is a token. Typographic quotes are different bytes, so `customer’s` no longer matches the merges that cover the straight apostrophe.

The correct answer has a cost the count hides. Prompt caches match on the prefix, so moving a paragraph to the top invalidates every cached prefix that included the old first paragraph. Equal token count is not equal bill.

## Common mistakes

- Treating the token count as a property of the text rather than of the text and the encoding together.
- Assuming that whitespace and punctuation edits are free.
- Equating an unchanged token count with an unchanged bill when the prompt is cached by prefix.
