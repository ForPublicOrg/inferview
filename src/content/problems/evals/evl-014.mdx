## Question

<Callout kind="interview" label="As a public question bank phrases it">
"How do you compare two models or prompts in a statistically rigorous way?"
</Callout>

A concrete version. You run a 300-case suite on the current prompt and a candidate, same cases, binary pass or fail per case. The baseline passes 246 (82.0%), the candidate 238 (79.3%). Their 95% Wilson intervals are 77.3% to 85.9% and 74.4% to 83.5%, so they overlap. Looking case by case, 12 cases passed before and fail now, and 4 failed before and pass now. Every other case has the same result in both runs.

If the prompt change made no difference, each of the 16 flips would be equally likely to go either way. Estimate the **one-sided p-value**, the probability of 12 or more of the 16 flips going against the candidate under that assumption, in percent.

## Hints

<details class="hint"><summary>Hint 1</summary><p>Only the 16 discordant cases carry information about the difference. The 284 that agree cancel out.</p></details>
<details class="hint"><summary>Hint 2</summary><p>Under the null, the number of regressions among 16 flips is Binomial(16, 0.5). Sum the upper tail from 12.</p></details>
<details class="hint"><summary>Hint 3</summary><p>C(16, 12) = 1,820 and 2^16 = 65,536.</p></details>

## Answer

<Depth>
<Fragment slot="short">
<p>About 3.8%. Under the null, regressions among the 16 flips follow Binomial(16, 0.5), and P(X ≥ 12) = (1,820 + 560 + 120 + 16 + 1) / 65,536 = 2,517 / 65,536 = 0.0384. That is below 5%, so the paired test says the candidate is worse even though the two intervals overlap. Overlapping intervals are the wrong test for paired data, because they ignore that both runs used the same cases.</p>
</Fragment>
<Fragment slot="long">
<p>Why pair. Each case is its own control. The 284 cases with the same result say nothing about the difference; the comparison lives in the flips. Comparing two marginal intervals treats the runs as independent samples and throws that pairing away, which makes the test far too conservative.</p>
<p>The test. The exact sign test on discordant pairs, which is McNemar's test in its exact form: X ~ Binomial(16, 0.5), one-sided p = P(X ≥ 12) = 0.0384. A two-sided p doubles it to 0.077, so state up front which question the gate asks; for "did the change make things worse?" one-sided fits.</p>
<p>Approximations. McNemar's chi-squared with continuity correction gives (|12 - 4| - 1)² / 16 = 49/16 = 3.06, z = 1.75, one-sided p about 0.040, close to exact. Without the correction, 64/16 = 4.0, z = 2.0, one-sided p about 0.023, noticeably too small at this sample size. With only 16 flips, use the exact test.</p>
<p>What a rigorous comparison adds. Measure the noise floor by running the baseline against itself; if identical runs flip several cases, some of these 16 are noise. Decide alpha and the metric before looking. If you gate on many metrics, expect some to look significant by chance. And read the 12 regressions: if they share a cause, that is more convincing than any p-value.</p>
</Fragment>
<Fragment slot="followups">
<ul>
<li><em>What if there were 120 flips, 64 against and 56 for?</em> Then the difference is small relative to the churn; the test will not reject, and the more interesting finding is that the prompt change altered 40% of outcomes.</li>
<li><em>How would you compare two models on a continuous score?</em> A paired test on per-case differences, such as a paired t-test or a bootstrap of the mean difference, again using the same cases.</li>
<li><em>How many cases would you need?</em> It depends on the expected number of flips, not on the total. Estimate the flip rate from past changes and size the suite so a regression of the size you care about produces enough discordant cases.</li>
</ul>

### Worked calculation

Upper tail of Binomial(16, 0.5) from 12:

- C(16, 12) = 1,820
- C(16, 13) = 560
- C(16, 14) = 120
- C(16, 15) = 16
- C(16, 16) = 1
- sum = 2,517; 2^16 = 65,536; p = 2,517 / 65,536 = 0.0384, or 3.84%

The accepted band, 3 to 5%, covers the exact answer and the continuity-corrected approximation (4.0%). The uncorrected normal approximation, 2.3%, falls outside it, which is the point: with this few flips it is too optimistic.

The overlapping Wilson intervals, for the record: baseline 246/300 gives 0.773 to 0.859, candidate 238/300 gives 0.744 to 0.835.

## Follow-ups

- *A teammate says "79.3 is inside the baseline's interval, so it's noise". What do you say?* The interval describes uncertainty about the baseline's true rate from a sample, not the effect of a change measured on the same cases. The paired test is the right one.
- *Should the gate block?* At a pre-agreed alpha of 0.05 one-sided, yes, and the pull request should list the 12 cases that broke.
- *What else would you check before blocking?* That the 12 regressions are not concentrated in near-duplicate cases, which would overstate the evidence.

## Common mistakes

- Comparing two unpaired intervals and declaring no difference.
- Using the normal approximation on a handful of flips.
- Choosing one-sided or two-sided after seeing the result.
- Reporting the p-value without the list of cases that flipped.
